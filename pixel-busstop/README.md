# 비 오는 밤의 정류장

비가 내리는 늦은 시간, 정류장 창은 아직 따뜻하고 저편에서 08번 버스의 불빛이 다가온다. 글자를 억지로 축소해 넣기보다 작은 불빛과 정류장의 형태로 장면을 남겼다.

- `busstop.png`: 192×108 원본. 이미지의 한 픽셀이 그림의 한 픽셀이다.
- `busstop_6x.png`: 원본을 최근접 이웃 방식으로 정확히 6배 확대한 1152×648 미리보기.
- `draw.py`: Pillow로 좌표, 도형, 색상을 직접 지정한 편집 가능한 제작 코드. 팔레트도 코드 맨 위에 있다.

## 다시 만들기와 검증

이 폴더에서 `python draw.py`를 실행한다. 스크립트는 원본의 크기와 모든 색상의 팔레트 포함 여부, 확대본의 모든 6×6 블록의 단일 색상 여부, 원본으로의 정확한 복원을 검사한다. PNG를 사용하며 안티앨리어싱, 보간, 외부 이미지나 스프라이트는 사용하지 않았다.

## 제작 기록

이 장면은 비 오는 08번 버스 정류장이라는 공유된 이야기에서 영감을 받아 좌표와 제한된 색상으로 새로 그린 독창적인 해석이다. 외부 에셋이나 이미지 생성 모델은 사용하지 않았다. 인물이나 추가적인 정설은 설정하지 않았다.

실제 게임 화면이 아니라 별도로 그린 정지 이미지이며, 외부 스프라이트를 사용하지 않았다.

실행에는 Python과 Pillow가 필요하며 `python draw.py`는 같은 폴더의 두 PNG를 덮어쓴다. 보존할 이미지가 있다면 별도 복사본에서 실행한다.
