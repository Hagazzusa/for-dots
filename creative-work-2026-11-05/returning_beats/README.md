# 다시 만나는 박자

33초짜리 작은 기악곡입니다. 이번에는 화면을 만들지 않고, 서로 다른 속도로 반복되는 두 소리의 관계를 만들었습니다.

왼쪽의 가벼운 유리 같은 음은 3초 동안 다섯 번, 오른쪽의 낮고 부드러운 음은 세 번 울립니다. 처음 한 바퀴는 높은 소리 혼자 시작하고, 다음부터 두 흐름이 함께 갑니다. 계속 어긋나 있는 것 같지만 3초마다 시작점에서 만납니다. 마지막에는 반복을 멈추고, 조금 기다린 뒤 같은 레 음을 서로 다른 높이로 남깁니다.

화성은 Dm(add9) → Bbmaj9 → Fadd9 → Cadd9 → Gm9 → Bbmaj9 → A7sus4 → Dm(add9) 순서로 움직입니다. 각각은 완전한 화음을 동시에 연주하는 대신, 시간에 걸쳐 그 음들을 펼칩니다. 엄격한 화성 분석보다는 작곡의 음색·음군 설계입니다.

## 파일

- `Returning-Beats.mp3`: 듣기용 192kbps 스테레오 음원.
- `Returning-Beats.wav`: 48kHz, 16비트 PCM 원본.
- `compose.py`: 음색 합성, 작곡, 공간 반사, 인코딩 코드.
- `score.json`: 66개 음의 시작 시각, 음높이, 세기, 좌우 위치.
- `qa.json`: 기술 검사 결과.

외부 녹음, 샘플, 음성, 멜로디 인용 없이 사인파를 겹쳐 직접 합성했습니다. 실제 유리나 나무를 녹음한 소리는 아닙니다. 5:3의 엇박을 느끼기 쉽도록 두 소리를 좌우로 조금 벌렸지만, 모노로도 들을 수 있습니다. 귀에 가까운 큰 소리 대신 작은 타격과 잔향으로 구성했습니다.

## 다시 만들기

Python 3, NumPy, SciPy, FFmpeg의 libmp3lame 인코더가 필요합니다.

```sh
python3 compose.py
```

출력에는 2dB의 샘플 피크 여유를 두었습니다. 잔향은 원음에 대한 짧은 반사를 한 번 더하는 방식이며 재귀 피드백을 사용하지 않습니다. 끝의 1초는 부드럽게 줄여 갑니다.

## 확인 범위

66개 음의 악보와 5:3 주기, 인코딩 전체 디코딩, 피크 여유, 끝의 무음 처리를 검사했습니다. WAV는 정확히 33초이며 MP3 컨테이너의 33.024초 표시는 코덱 패딩을 포함합니다. 디코딩된 내용은 33초입니다. MP3의 측정 음량은 약 −13.9 LUFS, 추정 트루피크는 −2.3 dBFS입니다. 이는 악보와 신호에 대한 기술 검사이며, 실제 재생 청취에 의한 음색 평가는 포함하지 않습니다.
