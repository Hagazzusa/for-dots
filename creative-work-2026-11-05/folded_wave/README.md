# 접힌 파도

한 장의 파란 띠를 서로 다른 높이로 접고, 그 앞에 주황색 구 하나를 놓았습니다. 곡선을 따라 흐르는 대신, 방향이 갑자기 바뀌는 면과 바닥에 떨어지는 그림자로 파도를 만들어 본 가상 조각입니다.

이번에는 건물이나 인물의 사정 없이 색과 형태만 남겼습니다. 같은 파랑도 빛을 받는 면과 안쪽 면에서 다르게 보이고, 구의 둥근 실루엣이 접힌 면의 날카로운 선과 대비됩니다.

## 파일

- `Folded-Wave.png`: 최종 정사각형 렌더.
- `Folded-Wave.blend`: 편집 가능한 원본 3D 장면.
- `build.py`: 장면을 직접 만드는 제작 코드.
- `render_conditions.json`: 실제 렌더 조건.
- `qa.json`: 최종 확인 기록.

띠는 연결된 일곱 개의 면으로 이루어져 있습니다. 양 끝에 바닥과 만나는 평평한 부분을 두었고, 얇은 두께와 작은 모서리 반경을 더했습니다. 주황색 구는 별도 물체입니다. 구가 굴러가거나 종이가 접히는 과정을 시뮬레이션한 결과는 아닙니다.

외부 이미지, 텍스처, 모델을 사용하지 않았습니다. 실제 제작 가능한 구조물인지 또는 자체 무게를 지탱할 수 있는지를 검증한 설계도는 아닙니다.

## 다시 만들기

Blender 4.3.2, Cycles CPU, 2스레드를 사용합니다.

```sh
blender -b -t 2 --python build.py -- --preview
blender -b -t 2 --python build.py
```

미리보기는 700 × 700, 32표본입니다. 최종 이미지는 1200 × 1200, 160표본입니다. 디노이징을 사용하지 않아 미세한 입자가 남습니다. 모든 출력은 스크립트 폴더에 저장하며, Blender의 출력 경로는 상대 경로입니다. PNG의 날짜·텍스트 메타데이터는 픽셀·색상 정보를 유지한 채 제거합니다.

## 확인

최종 이미지의 실제 픽셀을 확인했습니다. 접힌 면의 연속성과 주황색 구의 분리, 양 끝의 바닥 접점이 읽히고 주요 물체가 화면 밖으로 잘리지 않습니다. 배경은 순백색보다는 따뜻한 회색으로 나왔습니다. 미리보기는 독립 검토를 받았고, 최종 Blender 파일을 다시 열어 일곱 면, 렌더 설정과 상대 출력 경로, 외부 이미지가 없음을 확인했습니다. 그림자 부분에는 미세한 렌더 입자가 남습니다.
