# 마지막 우산

문은 닫혔지만 처마의 불은 아직 켜져 있습니다. 살구색 우산 하나를 펴서 말리는 동안, 문턱 바깥 고인 물이 조용히 빛을 받습니다.

누가 두고 갔는지, 곧 돌아올지는 정하지 않았습니다. 기다리는 사람을 직접 그리는 대신, 잠깐 남겨진 물건과 빈 자리를 만들었습니다.

## 작품과 원본

- `Last-Umbrella.png`: 정사각형 최종 렌더.
- `Last-Umbrella.blend`: 직접 편집 가능한 Blender 장면.
- `build.py`: 외부 에셋 없이 장면을 다시 만드는 제작 코드.
- `validation.json`: 실제 실행의 버전, 표본 수, 외부 이미지 사용 여부.

이전 세탁소 작품과 분리된 독립 3D 정물입니다. 실제 장소를 재현하거나 게임에 추가한 장면은 아닙니다. 문서, 이미지, 메시 등 작품 내용은 모두 이번 작업에서 직접 만들었습니다.

## 공간과 형태

하나의 직교투영 카메라로 문, 벤치, 우산과 문턱을 함께 봅니다. 바닥을 기준으로 벤치 다리를 배치했습니다. 우산은 8개의 곡면 조각과 방사형 살, 가장자리 선, 손잡이와 작은 받침으로 구성됩니다. 천은 색이 조금씩 다른 패널로 나누었고, 펼친 우산을 안정적으로 말릴 수 있게 가상의 작은 받침을 두었습니다.

단위는 대략 미터에 대응합니다. 문 높이는 2.09, 우산 지름은 1.38입니다. 벤치 좌판 윗면은 0.53, 포치 바닥은 0.11이므로 앉는 높이는 약 0.42입니다. 빗물은 바닥 위에 놓은 얇은 불규칙 면이며, 유체 시뮬레이션이 아닙니다. 벽의 큰 색면과 지붕, 우산의 곡면이 대비되도록 만들었습니다.

## 다시 만들기

Blender 4.3.2의 Cycles CPU를 사용했습니다.

```sh
blender -b -t 3 --python build.py -- --preview
blender -b -t 3 --python build.py
```

미리보기는 650 × 650, 20 표본입니다. 최종 이미지는 1300 × 1300, 192 표본입니다. 디노이징을 사용하지 않아 미세한 입자가 남습니다. 저장 경로는 스크립트 폴더를 기준으로 하며, Blender 파일의 이미지 출력 경로는 상대 경로입니다. PNG의 텍스트·날짜 메타데이터는 픽셀이나 색상 정보 변경 없이 제거합니다. 외부 이미지, 다운로드한 모델, 폰트는 없습니다.

## 확인 범위

최종 1300 × 1300 출력의 실제 픽셀을 확인했습니다. 우산의 형태와 손잡이, 벤치, 천, 문, 등과 빗물이 구별됩니다. 독립적인 소스 검토에서 발견한 우산대·바닥 접점·지붕 지지대의 작은 틈을 고친 뒤 최종 렌더를 만들었습니다. `qa.json`에 확인 결과를 기록했습니다. 치수나 물 표현을 실제 제품·건축 설계의 검증으로 해석하지 않습니다.
