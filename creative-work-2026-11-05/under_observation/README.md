# 확인 중

두 사람이 등장하는 독립적인 짧은 희곡입니다. 작은 수리점에서 잘 돌아가는 선풍기와, 자기 가게에서는 멈췄다고 말하는 손님을 두었습니다. 어느 쪽이 맞는지 증명하는 반전 대신, 원인을 아직 모르는 상태에서 다음 행동을 정해야 하는 장면을 썼습니다.

수진은 근거 없이 부품을 갈 수 없고, 경자는 물건을 맡기러 올 때마다 가게를 닫아야 합니다. 상대의 말을 받아들이는 일이 단지 더 정확한 표현으로 끝나지 않도록, 점검 시간과 돈, 연락 약속, 작은 선풍기의 대여에 비용과 한계를 남겼습니다. 큰 선풍기는 끝까지 멈추지 않습니다.

## 읽기

- `output/pdf/Under-Observation.pdf`: 읽기용 5쪽 대본.
- `play.txt`: 편집 가능한 UTF-8 원문.
- `build_pdf.py`: 한글 글꼴 부분 포함과 대본 조판 코드.
- `verify.py`, `qa.json`: 원문 누락, 글자 위치, 최종 시각 검토 기록.

외부 작품의 인물이나 대사를 가져오지 않았습니다. 실제 사람이나 수리 사례를 기록한 작품이 아니며, 기기 진단·수리 안내도 아닙니다. 글꼴은 SIL Open Font License 1.1의 Noto Serif CJK KR과 Noto Sans CJK KR을 부분 포함했습니다.

## 다듬은 부분

초고에서는 가격과 대여 기한이 흐렸고, 후반 대사가 같은 주제를 여러 번 설명했습니다. 가격은 만원에 당일 여섯 시까지 재점검을 포함하는 것으로, 연락은 다음 날 열한 시 전으로, 대여는 모레까지로 고정했습니다. 생활 대화보다 재치 있게 들리는 문답을 덜고, 의자와 두 대의 선풍기를 옮기는 행동을 남겼습니다.

## 검증과 한계

원문의 비어 있지 않은 107줄이 최종 PDF에서 모두 추출되는지 확인했습니다. 5쪽 전체를 렌더해 한글 표시, 줄바꿈, 여백과 페이지 흐름을 검토했습니다. 별도의 본문 검토에서 거래 조건과 소품 이동의 모순을 수정했습니다.

실제 배우와 낭독하거나 공연하지 않았습니다. 말의 호흡과 침묵의 길이는 실제 낭독에서 달라질 수 있으므로 공연 시간을 확정하지 않았습니다. PDF/UA 태그는 없으며 일반 텍스트 원문을 함께 보존했습니다.

## 다시 만들기

Python의 reportlab, fontTools, pypdf, PyMuPDF와 Poppler가 필요합니다. 코드에 명시된 Noto CJK 시스템 글꼴이 있어야 합니다.

```sh
python3 build_pdf.py
pdftoppm -scale-to 1000 -png output/pdf/Under-Observation.pdf tmp/pdfs/final
python3 verify.py
```

이 작업은 기존 작품을 수정하지 않았습니다. GitHub 게시 요청이나 재시도도 수행하지 않았습니다.
