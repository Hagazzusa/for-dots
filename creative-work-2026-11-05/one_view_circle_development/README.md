# 원을 지나서 돌아오기

‘한 자리에서만 원’을 발전시킬 가치가 있는지 확인하기 위한 저해상도 영상 실험입니다. 현재 판단은 고해상도 제작 보류입니다. 완성작이 아닌 연구용 미리보기로 보존합니다.

- `Passing-the-Circle-study.mp4`: 32초, 320 × 320, 12fps, 384프레임, 무음.
- `Passing-the-Circle-preview.blend`: 카메라 이동을 포함한 실험 장면.
- `study.py`: 기존 장면을 읽어 궤적 검사, 시험 이미지, 미리보기를 제작.
- `encode_preview.py`, `verify_scene.py`: 인코딩과 원본 보존·장면 검사.
- `framing-study.json`, `crossing-analysis.json`, `preview-qa.json`: 검사 기록.
- `PLAN.txt`, `REVIEW.txt`: 계획과 비판적 검토 결과.

처음 4초 정면, 7초 동안 오른쪽으로 이동, 3초 측면 정지, 10초 동안 정면을 통과해 왼쪽으로 이동, 4초 동안 처음으로 복귀, 마지막 4초 정지하는 구성입니다. 카메라 높이 2m와 48mm 렌즈를 고정했습니다. 조각·조명·배경은 이전 장면과 같습니다.

시간 구성과 프레이밍을 먼저 판단하려고 전체 미리보기는 계획의 480px보다 낮은 320px와 4표본으로 렌더했습니다. 별도의 시험 이미지는 480px, 8표본입니다. 미세한 입자가 보이는 것은 이 단계의 의도된 품질 한계이며, 최종 작품의 화질로 제시하지 않습니다.

원본 장면 해시와 비카메라 물체·재질 색·조명 설정의 일치를 확인했습니다. 첫 프레임과 마지막 원본 프레임은 동일합니다. MP4는 손실 압축이므로 두 프레임의 픽셀까지 동일하다고 주장하지 않습니다. 전체 디코딩은 통과했고 실제 출력에서 대표 프레임을 확인했습니다. 정상 속도 재생 감상과 관객 반응 검증은 하지 못했습니다.

제작은 Blender와 FFmpeg를 순서대로 실행합니다. 렌더 중에 인코딩을 병렬로 시작하지 않습니다. 기존 `one_view_circle` 폴더는 읽기만 했습니다. GitHub 게시·재시도·새 승인 요청은 수행하지 않았습니다.
