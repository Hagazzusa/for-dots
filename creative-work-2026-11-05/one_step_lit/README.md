# 문턱에 남은 빛

《마지막 우산》의 3D 정물과 짧은 소설 《불을 끄는 순서》를 이어 보는 12초 무성 장면의 구성안입니다. 새 등장인물이나 장소를 늘리지 않고, 이미 있는 등 하나의 상태 변화에 집중합니다.

## 세 장면

1. **0–4초: 불을 끈 가게, 켜진 처마.** 펼친 우산과 접힌 수건, 닫힌 문을 함께 봅니다. 사람은 화면에 들어오지 않습니다. 우산의 젖은 천을 흔드는 등 불필요한 움직임은 넣지 않습니다.
2. **4–6초: 처마 등이 꺼집니다.** 같은 구도를 유지합니다. 형태가 사라지는 암전 대신, 차가운 환경광에 남은 물체와 바닥을 보여 줍니다. 이 2초 동안 설명 자막은 없습니다.
3. **6–12초: 등이 다시 켜집니다.** 처음 구도를 잠시 유지한 뒤 문턱 쪽으로 아주 천천히 가까워집니다. 마지막에는 닫힌 문보다, 길과 포치 사이의 낮은 단차가 더 잘 보이게 마칩니다.

영상은 불이 다시 켜진 상태에서 끝내고 꺼짐으로 반복하지 않습니다. 《불을 끄는 순서》는 영상 옆에서 별도로 읽을 수 있게 둡니다. 소설의 이유를 화면 위에 설명하거나 실제 대사를 녹음하지 않습니다.

## 먼저 확인한 것

`01-light-off.png`와 `02-light-on.png`는 같은 카메라·형상·노출에서 만든 조명 시험입니다. 처마의 면광원과 전구 재질의 발광만 한 쌍으로 끄고 켰습니다. 최종 애니메이션이나 안전성 검증이 아닙니다.

두 이미지의 실제 픽셀을 확인했습니다. 꺼진 상태에서도 문턱은 남아 보입니다. 켜진 상태에서는 포치 바닥과 길의 밝기 차이, 우산과 벤치의 그림자가 더 뚜렷합니다. 따라서 사라졌던 장애물이 나타나는 효과로 과장하지 않고, 익숙한 길을 조금 더 읽기 쉽게 남겨 두는 동작으로 연출합니다.

기존 정물보다 늦은 저녁을 상정하여 환경광을 낮췄습니다. 이 낮춘 환경광은 두 시험 이미지 사이에서는 동일합니다. 비교 조건은 `conditions.json`, 재현 코드는 `render_study.py`에 있습니다. 원래 작품의 장면이나 최종 이미지는 수정하지 않습니다.

```sh
blender -b -t 2 --python render_study.py -- ../last-umbrella/Last-Umbrella.blend
```

## 다음 제작에서 지킬 것

- 등이 켜지는 것과 문턱이 읽히는 변화가 실제 출력에서 연결되어야 합니다. 필요하면 카메라를 낮추거나 문턱 가까운 컷으로 바꾸되 두 상태를 같은 조건에서 비교합니다.
- 물웅덩이에 존재하지 않는 물결·광학 효과를 덧붙여 의미를 만들지 않습니다. 현재 물 표면의 단순한 표현을 유지합니다.
- 소리를 넣더라도 새로 만든 작은 스위치 소리와 짧은 무음만 검토합니다. 아직 음원은 만들지 않았습니다.
- 12초 영상, 카메라 이동, 사운드, 실제 게임 연동은 아직 구현하지 않았습니다. 이번 결과는 두 장의 시험 렌더와 구성안입니다.
