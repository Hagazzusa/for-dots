# 한 자리에서만 원

정면에서 보면 하나의 원처럼 맞물립니다. 카메라가 옆으로 움직이면, 여덟 조각이 서로 다른 깊이와 크기로 흩어져 있다는 것이 드러납니다. 조각은 움직이지 않습니다.

같은 물체를 보는 자리가 바뀔 때, 처음에 당연해 보이던 모양이 얼마나 쉽게 풀리는지가 궁금해서 만든 가상 조각입니다. 나눠진 원을 억지로 다시 붙이는 대신, 맞아 보이는 한 자리를 만들고 거기서 천천히 벗어나 봤습니다.

## 결과

- `One-View-Circle.mp4`: 8초 무성 영상. 정면 2초, 이동 4초, 옆모습 2초.
- `One-View-Circle.blend`: 실제 3D 조각과 카메라 애니메이션.
- `build.py`, `encode.py`: 조각 제작·렌더·영상 인코딩 코드.
- `projection_check.json`: 정면의 기본 정점 투영 검사와 조각 배치.
- `qa.json`: 실제 출력 파일 확인 기록.

영상은 정면의 80mm 카메라에서 시작합니다. 옆으로 70도 돌며 조금 높아지고, 조각 전체가 보이도록 렌즈를 48mm로 넓힙니다. 이동 중 조각이 화면 밖으로 나가지 않도록 화각을 더 일찍 넓히는 구간도 있습니다. 시점 변화와 줌아웃을 함께 사용한 연출이며, 고정 화각만으로 비교한 실험은 아닙니다.

## 모양을 맞춘 방법

정면 카메라에서 가상의 평면 위 원을 향해 선을 긋고, 각각의 조각을 그 선 위로 앞뒤 이동했습니다. 멀어지는 조각은 같은 비율로 키우면 정면에서는 원래 크기로 보입니다. 조각마다 거리를 다르게 정했기 때문에 옆에서는 하나의 평면에 놓여 있지 않습니다.

이 관계를 조각 앞면의 기본 정점 400개에서 검사했습니다. 가장 큰 차이는 정규화한 화면 좌표에서 약 0.00000012입니다. 이 검사는 모서리 다듬기와 두께가 만든 윤곽, 그림자, 모든 픽셀, 다른 모든 시점까지 증명하는 것은 아닙니다. 실제 이미지는 따로 확인합니다.

바닥에 생기는 희미한 그림자도 공간이 나뉘어 있다는 단서로 남겼습니다. 조각은 지지대 없이 떠 있는 가상 물체이며, 실제 설치물이나 제작·구조 도면은 아닙니다. 외부 모델·텍스처·이미지를 사용하지 않았습니다.

## 다시 만들기

Blender 4.3.2와 FFmpeg 7.1.5를 사용합니다.

```sh
blender -b -t 2 --python build.py -- probes
blender -b -t 2 --python build.py -- film
python3 encode.py
```

정지 시험은 720 × 720, 32표본입니다. 영상은 640 × 640, 24표본, 초당 12프레임입니다. Blender 렌더가 완전히 끝난 뒤 별도 명령으로 영상을 인코딩합니다. 인코더도 2스레드로 제한합니다. 영상에만 약한 시공간 노이즈 감소를 적용하며, 음성·음악은 넣지 않습니다.

정지 구간은 정확히 같은 렌더를 재사용합니다. 이동 구간은 매 프레임 실제 3D 장면에서 렌더합니다. 이미 있는 중간 프레임은 제작 코드의 해시가 같을 때만 재사용합니다. 코드가 바뀌면 중단하므로, 중간 렌더와 `frame_revision.json`을 별도로 보관하고 새 폴더에서 다시 시작해야 합니다. 최종본과 중간 검사 이미지는 구분합니다.

## 최종 확인

최종 MP4 전체 디코딩을 통과했으며, 8초·96프레임·640 × 640·12fps·무음임을 확인했습니다. 실제 영상에서 추출한 대표 프레임 여섯 장으로 원의 정렬, 깊이의 드러남, 화면 여백, 배경 연결을 확인했습니다. 미세한 렌더 입자는 남아 있습니다. 저장한 Blender 파일도 다시 열어 여덟 조각이 움직이지 않고 카메라만 변하는지 확인했습니다.
