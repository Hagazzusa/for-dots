# 옮기는 동안

대사 없는 네 칸 만화. 두 사람이 옮기던 벤치를 내려놓는다. 한 사람이 먼저 앉고, 다른 사람도 잠깐 함께 앉는다.

관심은 운반의 순서보다 빈 자리를 권하는 손짓에 있다. 여섯 칸으로 시작했지만, 내려놓는 중간 동작과 둘 다 서 있는 장면을 덜어 네 칸으로 줄였다. 손과 시선이 바뀌는 순간에 더 많은 주의가 남는 구성을 택했다. 두 사람의 관계나 어디까지 가려던 것인지는 정하지 않았다.

## 완성본

- `While-Carrying.png`: 1800×1279 이미지.
- `output/pdf/While-Carrying.pdf`: 같은 그림의 벡터 PDF.
- `description.txt`: 그림의 텍스트 설명.

외부 그림이나 모델을 사용하지 않고 곡선과 도형으로 그렸다.

## 재현

Python 3와 ReportLab, PyMuPDF, Pillow 및 Poppler가 필요하다.

```sh
mkdir -p output/pdf studies
python3 draw.py
pdftoppm -png -singlefile -scale-to 1800 output/pdf/While-Carrying.pdf While-Carrying
python3 verify.py
```

`draw.py`는 네 칸 완성본을 만든다. 생성한 PDF를 다시 래스터화한 뒤 검사를 실행한다.

## 확인한 범위

모든 도형의 경계, 네 칸의 구분, 인물 색의 연속성, 벤치의 길이와 바닥 접점을 확인했다. 첫 칸에서 벤치는 들려 있고, 이후 세 칸에서는 앞다리가 바닥에 닿는다. 무릎의 꺾임과 앉은 높이, 손짓과 시선도 최종 그림에서 확인했다.

설명 없이 그림을 읽는 검토에서는 운반, 먼저 앉기, 자리 권하기, 함께 앉기가 전달되었다. 피로 정도나 두 사람의 감정까지 특정하지는 않는다. 이는 실제 독자 집단을 대상으로 한 반응 조사나 신체 동작의 물리적 검증은 아니다.

`qa.json`은 이번 완성본의 확인 기록이며, 재생성 후에는 시각 검토를 다시 해야 한다. `manifest.json`에 소스와 결과물의 SHA-256을 보존했다.
