# 공개 전 점검 도구

`check_public_assets.py`는 의도적으로 선택한 준비 디렉터리를 대상으로 하는 **표준 라이브러리 기반의 읽기 전용 메타데이터 패턴 검사기**입니다. 보안 인증, 완전한 비밀 정보 탐지기, 개인정보 맥락 해석기, 라이선스 검사 또는 공개 허가가 아닙니다.

다음 명령 블록의 주석은 원문 그대로 보존했습니다.

```sh
python3 tools/check_public_assets.py --directory garden-of-light
# Or select only tracked files of an explicit Git worktree:
python3 tools/check_public_assets.py --tracked .
python3 tools/test_check_public_assets.py
```

Python 3.8+가 필요하며 Git은 `--tracked`에만 필요합니다. 엔진, 플러그인, 네트워크 서비스, 자격 증명을 사용하지 않습니다. 실제 자격 증명 디렉터리가 아니라 변경을 멈춘 신뢰할 수 있는 준비 사본에서 실행하세요. 디렉터리를 순회할 때 심볼릭 링크를 따라가지 않습니다. 알려진 자격 증명 저장소 이름과 개발·설정 디렉터리는 내용을 읽지 않고 보고합니다. 자동 업로드, 편집, 삭제, 정리는 하지 않습니다.

## 검사 대상

- 선택된 UTF-8 텍스트 파일: 흔한 비공개 절대 경로 패턴과 제한된 종류의 자격 증명 유사 접두사·개인 키 표식. `password`나 `api_token = None` 같은 일반적인 소스 식별자는 자격 증명이 아닙니다.
- PNG: `tEXt`, 압축된 `zTXt`, `iTXt` 메타데이터, 크기를 제한한 압축 해제, 메타데이터 CRC. EXIF는 원시 패턴 검사를 하며, 무해한 해상도 데이터만 있더라도 **구조를 살펴보는 수동 검토가 필요합니다**. 픽셀은 디코딩하지 않습니다. `caBX` / C2PA 진위 메타데이터는 주장·인증서 내용을 디코딩하지 않고 출처를 수동 검토하도록 명시합니다. 그 존재만으로 의심스럽거나 비밀인 것은 아닙니다. 제거하지 않으며 암호학적 신뢰 체인 검증으로 취급하지도 않습니다.
- OpenEXR: 크기를 제한한 문자열 속성, 특히 절대 `File` 경로. 딥·멀티파트 파일은 네이티브 도구로 검토해야 합니다. 채널·픽셀 데이터는 디코딩하거나 바꾸지 않습니다.
- FreeCAD `.FCStd`: 크기를 제한한 ZIP 중앙 디렉터리와 XML 메타데이터(디코딩된 XML 값 포함). 압축 파일은 풀지 않으며 ZIP64는 보수적으로 미지원 처리합니다. 네이티브 바이너리 기하·속성은 별도로 검토해야 합니다. 엔티티 선언은 확장하지 않습니다.
- `.blend`: 압축 파일을 포함해 항상 **네이티브 도구를 통한 읽기 전용 수동 감사가 필요합니다**. 스크립트는 원시 문자열 검색만으로 Blender 검사가 충분하다고 간주하지 않습니다.
- 오디오, 영상, 그 밖의 미지원 형식: 암묵적으로 안전하다고 처리하지 않고 미검사·수동 검토 대상으로 명시합니다.

한도는 선택 경로 10,000개, 텍스트 파일당 4 MiB, PNG 텍스트·EXIF의 인코딩·디코딩 메타데이터 또는 EXR 헤더 1 MiB, CAD 항목 512개, ZIP 중앙 디렉터리·개별 XML 데이터 1 MiB, XML 전체 4 MiB입니다. 크기 초과, 잘못된 형식, 사용할 수 없는 데이터는 **불완전·수동 검토 대상**이지 정상 결과가 아닙니다. 실제 에셋이 정당하게 이 한도를 넘을 수도 있습니다. 이 한도는 선택된 메타데이터에 적용되며 전체 실행 시간이나 초기 디렉터리·Git 열거를 제한하지는 않습니다. 큰 작업 트리의 목록을 만들 때는 경로 수 한도를 검사하기 전에 메모리가 할당될 수 있습니다. 범위를 한정한 신뢰할 수 있는 준비 디렉터리를 사용하세요. 이 도구는 적대적인 파일 시스템을 격리하는 샌드박스가 아닙니다.

## 출력과 후속 검토

JSON 결과에는 상대 파일 위치와 고정된 사유 코드가 들어가며, 일치한 값이나 예외 메시지는 넣지 않습니다. 의심스러운 파일명은 가립니다. 일반적인 상대 이름까지 숨기는 것은 아니므로 출력을 검토 없이 공개해서는 안 됩니다.

종료 코드:
- `0`: 검사한 부분에서 대상 패턴을 찾지 못함. **공개 승인 아님**.
- `1`: 탐지 결과나 수동 검토 항목이 있음(의도적으로 지원하지 않는 파일 포함).
- `2`: 명시한 대상을 선택하거나 검사를 완료하지 못함.

모든 결과를 검토하고 미지원·네이티브 형식은 따로 살펴보세요. 절대 경로 표시는 의도적인 공개 코드 예시일 수 있고 자격 증명 유사 일치는 합성 테스트 자료일 수 있습니다. 반대로 인식하지 못하는 자격 증명, 인코딩된 텍스트, 비공개 의미는 이 유한한 패턴으로 찾아내지 못할 수 있습니다. 경고 억제나 자동 승인 기능은 없습니다. 검사 중 파일이 교체되는 상황은 이 작은 도구의 위협 모델 밖에 있으므로 변경을 멈춘 준비 사본을 사용하세요.

루트의 `verify_sources.py`는 별도로 체크포인트 바이트가 정확히 일치하는지 검증합니다. 무결성 해시를 메타데이터·개인정보 검토와 혼동하지 마세요. 합성 단위 테스트 묶음은 실제 비밀 정보 없이 가림 처리, 문제가 없는 인코더·소스 사례, 압축 PNG 메타데이터와 한도, EXR 경로, 크기가 제한된 CAD XML, 심볼릭 링크·저장소 제외, 추적 파일만 선택하는 동작을 검사합니다.

## 선택 파일을 동결 사본으로 보존하기

`freeze_allowlist.py`는 **로컬 파일 복사 도구**입니다. 읽기 전용 메타데이터 검사기와 달리, 명시적 allowlist에 적힌 원본 바이트만 새 디렉터리에 복사하고 원본·사본의 해시를 대조합니다. 저장소 전체를 수집하거나 GitHub·네트워크·자격 증명을 사용하지 않습니다. 공개 허가, 개인정보 판단, 라이선스 검사나 보안 인증을 대신하지 않습니다.

Python 3.8+의 표준 라이브러리만 필요합니다. `check_public_assets.py`의 제외 이름 상수만 재사용하므로 두 스크립트를 같은 폴더에 둡니다. Blender/Godot를 실행하지 않습니다.

```sh
# 선택은 사람이 검토한 정확한 상대 파일 이름의 JSON 배열입니다.
# 예: ["README.md", "assets/model.glb", "renders/final.png"]
python3 tools/freeze_allowlist.py \
  --source prepared-project \
  --allowlist selected-files.json \
  --destination snapshots/review-001
python3 tools/test_freeze_allowlist.py

# 복사 성공은 공개 승인이나 메타데이터 검토 완료가 아닙니다.
python3 tools/check_public_assets.py --directory snapshots/review-001/files
```

`--source`와 allowlist는 이미 존재해야 하며 destination의 부모 디렉터리도 먼저 준비합니다. destination은 원본 밖의 **아직 존재하지 않는 경로**여야 합니다. 출력은 다음과 같습니다.

- `files/`: 선택한 상대 구조 그대로의 바이트 사본. 권한·mtime·확장 속성까지 보존하는 파일시스템 백업은 아닙니다.
- `SNAPSHOT_MANIFEST.json`: 상대 `path`, 절대 `localpath`, 바이트 수 `size`, `sha256`, Git blob SHA-1 `sha`. Git blob 해시는 `blob <바이트 수>\0` 헤더를 포함합니다. Git 명령이나 원격 쓰기는 수행하지 않습니다.
- `INCOMPLETE`: 생성 시작부터 최종 검증·manifest 쓰기가 끝날 때까지 남는 표식. **표식이 있으면 완성 사본이 아닙니다.**

**완료 판정은 `INCOMPLETE`가 없고, `status=complete`인 정상 manifest가 존재하며, 나열된 모든 파일의 크기·해시가 일치하는 경우에만 합니다.** 표식이 없다는 사실만으로 성공이 아닙니다. 디렉터리 생성 직후 표식 생성 전에 중단되거나 표식 생성이 실패하면 빈 destination만 남을 수 있으며, 이것도 미완료입니다.

이 manifest의 **절대 localpath는 내부 작업용**입니다. 공개 프로젝트에 그대로 넣거나 루트 `SOURCE_MANIFEST.json`으로 사용하지 마세요. 전체 저장소의 공개용 무결성 목록은 기존 `verify_sources.py`로 별도로 갱신합니다. 사본의 콘텐츠·개인정보·출처는 기존 점검 도구와 필요한 네이티브 수동 감사로 판단합니다. PNG·EXR·C2PA·Blender 등 모든 파일의 메타데이터는 이 도구가 **변경하거나 삭제하지 않습니다**.

### 실패·재실행·동시 변경

- allowlist는 최대 1 MiB·10,000개입니다. 빈 목록, 중복 및 대소문자만 다른 별칭, 절대 경로, `..`, `.`·빈 경로 조각, 역슬래시·콜론·U+0000–U+001F 제어 문자를 거부합니다. 디렉터리가 아니라 일반 파일만 선택합니다.
- `.git`, `.godot`, 캐시·개발 환경과 알려진 자격 증명 저장소 이름을 선택하거나 그 아래를 source/destination으로 사용하지 않습니다. 선택 파일뿐 아니라 현재 확인하는 부모 경로의 심볼릭 링크도 거부합니다. 이는 알려진 이름 제외이며 모든 민감 파일을 찾아낸다는 뜻은 아닙니다.
- destination을 `mkdir`의 배타 생성으로 예약하므로 **기존 빈 디렉터리·파일·심볼릭 링크도 덮어쓰지 않습니다**. 같은 명령을 재실행하면 실패하고 기존 사본은 유지합니다.
- 파일별 복사 전·열기 직후·읽기 후의 장치/파일 식별자·크기·수정/변경 시간 등을 대조합니다. 복사한 바이트의 SHA-256/Git blob SHA를 확인하고, 마지막 파일 복사가 끝난 뒤 모든 선택 원본과 사본을 다시 읽어 대조합니다. 관찰된 변경·잘림·복사 오류가 있으면 완성으로 처리하지 않습니다.
- 실패나 강제 종료 시 **새로 만든 부분 사본도 자동 삭제하지 않습니다**. `INCOMPLETE`와 확인 가능한 파일을 보존하고, 재사용 대신 다른 새 destination을 선택합니다. 원본 또는 기존 사용자 데이터를 자동 정리하지 않습니다. 성공 때 제거하는 것은 이 실행이 만든 `INCOMPLETE` 표식 하나뿐입니다.
- 디렉터리 전체의 원자적 게시나 정전 후 내구성을 보장하지 않습니다. manifest가 있어도 `INCOMPLETE`가 남으면 미완료로 취급합니다. 완료 후 내용을 변경하면 기록된 해시와 달라집니다.

**변경을 멈춘 신뢰할 수 있는 준비 디렉터리**를 위한 도구입니다. stat/해시 재검사는 실수로 계속 저장되는 파일을 발견하는 데 도움이 되지만, 악의적인 프로세스의 교체·되돌리기 경쟁, 잠금 없는 여러 파일의 동일 순간 스냅샷, 다른 OS/파일시스템의 모든 동작을 보장하지 않습니다. 마지막 확인 이후 원본이 바뀔 수도 있습니다. 파일 총 용량·실행 시간 제한은 없으므로 필요한 공간을 먼저 확인하세요. 오류 출력에는 선택 경로·파일 내용 대신 일반 실패 안내만 표시합니다.
