# 다음 소품 제작의 판독성 체크리스트

[관찰 노트](README.md)의 교훈을 새 작업에서 다시 확인한다. 체크 완료는 일반 사용자 검증을 뜻하지 않는다.

- [ ] 설명을 읽기 전 첫 시선이 가는 대상과 처음 떠오르는 물건 이름을 적는다. 의도한 이름과 다르면 혼동을 만든 윤곽도 남긴다.
- [ ] 설명 대상은 **장면 이름 + 화면 위치 + 윤곽**으로 먼저 확인한다. 밝은 수리목과 왼쪽 도구처럼 가까운 다른 대상을 구분한다.
- [ ] 최종 표시 크기와 작은 크롭에서 기능을 암시하는 부위의 실루엣이 남는지 본다. 부품·재질 이름을 근거로 대신하지 않는다.
- [ ] 단순화 전후를 비교해 식별에 필요한 틈·기울기·끝 모양이 사라졌는지 확인한다. 외관 표현과 실제 기능 구현 여부를 따로 적는다.
- [ ] **빈 잔 / 차가 들어 있는 잔**은 액면·내벽·바닥 중 무엇으로 구별되는지 지목한다. 색이나 이야기만으로 상태를 단정하지 않는다.
- [ ] 배포할 렌더러의 실제 출력에서 시점·조명·축소 상태를 다시 본다. 다른 렌더러의 재질·검사 결과를 그대로 가져오지 않는다.
- [ ] 움직임·효과는 좌표·alpha·변화 픽셀뿐 아니라 방향·가림·주변 사물과의 관계가 읽히는지 확인한다. 영상은 정지 화면과 재생 구간을 구분해 기록한다.
- [ ] **의도 / 실제로 본 단서 / 남은 한계**를 한 줄로 남기고, 사용한 화면·소스·검사 기록을 연결한다. 기하 검사와 의미 해석을 분리한다.
- [ ] 채택 기준과 보류 조건을 먼저 정한다. 의미가 여전히 모호하거나 다른 단서를 가리면 강도를 올리는 반복 대신 보류하고 원본을 유지한다.
