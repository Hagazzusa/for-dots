# 읽기 중 버스 탑승 안내

정차한 버스의 탑승점 가까이 서 있으면 E는 읽던 글을 넘기는 대신 버스에 탄다. 이 기존 우선순위는 유지하되, 읽기 패널도 그 순간에는 **E 버스 타기**를 표시한다. 선택지가 있으면 1/2 안내를 함께 남기고, Q는 여전히 창만 닫는다. 버스가 출발하거나 탑승 반경을 벗어나거나 앉아 있으면 원래 읽기 안내로 돌아온다. 새 이야기·퀘스트·버스 대기 시간 변경은 없다.

Session의 `can_board_here()`를 실제 E 처리, HUD, 패널의 주입된 Callable이 공유한다. StoryPanel은 플레이어나 버스를 직접 찾지 않으며 독립 실행 시에는 기존 안내를 사용한다. 열린 패널만 매 프레임 현재 자격을 읽는다. 페이지·선택지·쪽지 Resource는 수정하지 않는다. 공통 설명은 앉은 독자에게도 맞도록 ‘읽는 동안에도 시간은 흘러요’로 바꿨다. Space 일시 정지에서는 시간과 게임 입력이 멈추는 기존 동작이 유지된다.

## 검증과 한계

- Godot 4.6.3 Compatibility에서 전체 실행 검사 52개 suite가 통과했다. 최종 강화한 전용 검사는 17항목 통과: InputEventKey E/Q 실제 dispatch, 정차·출발·반경 이탈·착석, 선택지/최장 안내 폭, 일시 정지 E 소비, 탑승, 새 밤, 전체 보기 복귀, 읽기 중 시계 진행, 독립 패널.
- 런타임 의존성만 묶은 PCK 191파일의 독립 경로 감사와 같은 17항목도 통과했다. 기존 도시 에셋의 UID를 찾지 못해 저장된 텍스트 경로를 대신 쓴다는 경고가 있어, 무경고 실행이라고 주장하지 않는다. 테스트·문서·QA 장면은 패킹하지 않았다.
- 실제 1180×812 임시 창에서 가장 긴 ‘탑승 + 선택지’ 안내가 잘리지 않는 것을 확인했다. 정차/읽기 상태를 미리 만든 검사 장면에서 S로 걸어 물러나면 읽기 안내, W로 돌아오면 탑승 안내로 바뀌었다. 1로 응답을 선택한 뒤 실제 E 입력으로 읽기 창이 닫히고 버스 결말에 들어가는 것도 확인했다.
- 이 화면 검사는 버스를 정상 대기 시간 내내 기다린 전 경로 플레이가 아니다. 출발·착석·전체 보기·일시 정지 복귀 조건은 자동 검사 근거다. 모든 해상도에서의 글자 크기/잘림을 검증한 것은 아니다.
- 네이티브 실행은 V-Sync 지원 경고와 ALSA 장치 부재 후 Dummy 오디오 대체를 기록했다. 소리를 직접 듣는 검사는 하지 않았으며 오디오 코드를 바꾸지 않았다.

재실행: `godot --headless --path . --script res://tests/reader_boarding_hint.gd` 또는 `bash tools/run_checks.sh`. 엔진의 가져오기 캐시와 테스트 로그가 생성될 수 있다.
