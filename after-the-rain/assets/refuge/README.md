# Glass Refuge 실시간 파생 에셋 — 512 목재 색상

`refuge.glb`는 저장소 루트의 `glass-refuge-wood-transfer/assets/refuge_512.glb`에 보존된 512 비교 시안과 같은 파일입니다. SHA256: `dc49841045f3d786bb725c0c411040014a1e039ad4318b7ecf68530c7ba05da8`. 크기는 3,856,564바이트로, 이전 단색 파생 에셋보다 239,564바이트 큽니다. 독립 실행 뷰어의 원본은 변경하지 않았습니다.

메시 노드 33개, 재질 표면 35개, 인덱스 삼각형 78,388개, 근사 PBR 재질 10개입니다. 내장된 512×512 아틀라스 하나가 원본 절차적 목재의 기본 색상만 전달합니다. 조명, AO, 노멀, 거칠기, 금속성 맵은 굽지 않았습니다. 게임의 충돌체, 비를 가리는 영역, 앉는 위치, 동적 펜던트는 그대로입니다. 식물, 풍경, 원본 조명은 제외했습니다.

원본 단색 에셋과 펼친 삼각형을 비교하면 목재의 최대 위치 차이는 약 2.67×10⁻⁷ 단위, 최대 노멀 각도 차이는 약 0.0156도입니다. 이는 작은 내보내기 수치 차이이며, 원본과 비트 단위로 같은 지오메트리라고 주장하지 않습니다. 목재 외 표면은 위치·노멀·재질·와인딩 비교가 일치했습니다. 별도 512/1024 비교 시안끼리의 접근자 바이트 일치는 원본과의 비교와 구별합니다.

비등방성 UV 밀도와 곡선 리브의 부드럽고 띠처럼 보이는 무늬는 남아 있습니다. 완전한 절차적 셰이더/Cycles 일치, 측정된 FPS 개선, 실측 건축이나 시공 검증을 뜻하지 않습니다. 런타임에는 형제 프로젝트가 필요하지 않습니다. 편집 소스와 재현 가능한 아틀라스·내보내기·검증 도구는 저장소 루트의 `glass-refuge/`, `glass-refuge-wood-transfer/`에 있습니다.

Godot 가져오기 설정은 이미지를 생성된 장면 안에 무손실로 포함합니다(`gltf/embedded_image_handling=3`). 따라서 자동 생성 외부 PNG가 필요하지 않습니다. [Godot 4.6 이미지 처리 방식](https://docs.godotengine.org/en/4.6/classes/class_gltfstate.html)을 참고하세요. 패키지 검증은 이 의존성 포함 여부를 별도로 확인합니다.
