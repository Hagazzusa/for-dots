# 검토 기록

## 선정

2026-11-17, 화면용 완성 일러스트로 선정했습니다. 배의 외형을 반복하되 길이·각도·색을 바꾸고, 오른쪽 아래의 빈 배 모양을 시선의 마지막 자리로 삼았습니다.

## 직접 본 것

- 최종 1440×1080 PNG를 열어 네 선체와 빈 자리 하나, 받침, 두 노, 작은 통이 서로 겹쳐 읽히지 않는지 확인했습니다.
- 최초에는 빈 자리의 외곽을 점선으로 그렸지만 도면처럼 보여, 옅은 연속 흔적으로 수정했습니다. 수정 후 PNG를 다시 열었습니다.
- 가장자리 잘림은 물결·해변에만 의도적으로 적용했습니다. 네 배의 끝은 잘리지 않습니다.
- 긴 그림자, 판재선, 모래의 결은 장식적으로 단순화했습니다. 실제 선체 치수나 광학 모델을 검증한 작업은 아닙니다.

## 실행한 검사

`python3 check.py` 통과. SVG XML 구조, 외부 이미지·스크립트 없음, PNG 크기·색상, 별도 임시 디렉터리 재생성 바이트 일치를 확인했습니다. 사용한 프로그램은 Python 3와 Inkscape입니다. 다른 버전의 렌더러까지 동일한 PNG 바이트를 보장하지 않습니다.

## 범위 밖

실물 인쇄, 관객 해석 검사는 하지 않았습니다. 게임 세계관이나 실제 장소의 기록이 아닌 독립 작품입니다.
