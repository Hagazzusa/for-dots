# 박수의 용도

커튼을 고르려고 박수를 치던 가게 주인에게 옆집 사람이 찾아옵니다. 같은 크기의 박수를 치는 일부터 뜻대로 되지 않는, 세 사람의 짧은 소설입니다.

[소설 읽기](story.md)

독립 작품입니다. 기존 작품이나 게임의 인물·설정을 잇지 않았습니다. 편집 원본과 읽기 파일은 `story.md` 하나로 보존합니다.

## 제작과 검토

박수를 감탄이 아닌 시험 신호로 쓰는 상황에서 출발했습니다. 시험과 식사 사이에 손의 용도가 바뀌도록 구성했습니다. 마지막 옆집 박수의 이유는 설명하지 않았습니다.

인물의 이동, 기사가 천을 내리는 시점, 전화 때문에 응답이 늦는 순서를 원고에서 확인했습니다. 마지막의 응답은 첫 벽 두드림과 연결됩니다. 등장인물의 임시 시험은 실제 방음 성능을 판정하는 방법으로 제시한 것이 아닙니다. 실제 낭독·독자 평가는 하지 않았습니다.

## 보존 검사

`python3 verify.py`로 원문의 UTF-8 형식과 보존 파일의 크기·SHA-256을 확인합니다. 이 검사는 문학적 완성도 평가가 아닙니다.
