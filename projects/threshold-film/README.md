# 문턱에 남은 빛

[12초 무성 영상 보기](Light-on-the-Threshold.mp4) · [편집 가능한 Blender 장면](Light-on-the-Threshold.blend)

《마지막 우산》의 장면과 《불을 끄는 순서》의 마지막 동작을 잇는 12초 무성 영상입니다. 닫힌 가게 앞의 등을 껐다 다시 켜고, 문턱 쪽으로 천천히 가까이 다가갑니다.

## 보기

- `Light-on-the-Threshold.mp4`: 640 × 640, 초당 12프레임, 12초. 음성·음악은 없습니다.
- `Light-on-the-Threshold.blend`: 조명 전환과 실제 3D 카메라 이동을 편집할 수 있는 장면.
- `build_film.py`와 `encode_film.py`: 렌더와 인코딩을 각각 재현하는 제작 코드.
- `render_conditions.json`: 실제 제작 조건.
- `qa.json`: 최종 확인 기록.

0–4초에는 등이 켜져 있고, 4–6초에는 꺼져 있습니다. 6초에 다시 켜지고, 8–12초에 카메라가 문턱 쪽으로 천천히 이동하며 직교투영 범위를 좁힙니다. 불이 켜진 상태에서 끝납니다. 꺼진 상태에서도 문턱은 보이며, 켜지면 바닥과 길의 밝기 차이가 더 뚜렷해집니다.

새 사람이나 공간을 만들지 않았습니다. 우산을 남긴 사정은 독립적인 소설의 설정이며 기존 게임 사건이나 실제 가게를 기록한 영상이 아닙니다. 문턱의 안전성이나 현실의 조도 기준을 검증한 실험도 아닙니다.

## 만들기

Blender 4.3.2의 Cycles CPU와 FFmpeg 7.1.5를 사용했습니다. 원본 `Last-Umbrella.blend`는 읽기만 하며 수정하지 않습니다. 아래 예시는 현재 작업 폴더의 형제 디렉터리 `last-umbrella`를 가리킵니다. 다른 곳에 원본을 두었다면 마지막 인자를 그 경로로 바꾸면 됩니다.

```sh
blender -b -t 2 --python build_film.py -- ../last-umbrella/Last-Umbrella.blend --probe
blender -b -t 2 --python build_film.py -- ../last-umbrella/Last-Umbrella.blend
python3 encode_film.py
```

`--probe`는 처음, 소등, 마지막 구도를 먼저 렌더합니다. 전체 제작은 두 정지 상태와 이동 구간의 48개 장면을 렌더합니다. 카메라와 빛이 변하지 않는 시간에는 동일한 렌더를 정확히 재사용하며, 새 시점은 3D 장면에서 직접 렌더합니다. 그림을 확대해서 카메라 이동처럼 보이게 하는 방식이 아닙니다.

렌더가 끝난 뒤 Blender를 종료하고 별도 명령으로 인코딩합니다. 동시에 두 작업을 실행하면 이 환경의 메모리 한도를 넘을 수 있어, 인코더도 2스레드로 제한합니다.

각 장면은 24표본으로 렌더했습니다. 이 실행 환경의 Blender에는 디노이저가 없어서, 영상 인코딩 단계에서 약한 FFmpeg `hqdn3d` 필터로 입자를 줄였습니다. 세밀한 입자와 낮은 프레임률의 움직임은 남습니다. H.264/yuv420p로 저장하고 앞부분에 재생 정보를 둡니다. 오디오 트랙은 만들지 않습니다.

중간 렌더가 이미 있으면 다시 쓰지 않습니다. 장면이나 제작 조건을 바꿔 재제작하려면 새 작업 폴더에서 실행하거나 기존 중간 렌더를 별도로 보관한 뒤 비워야 합니다. 출력 폴더는 스크립트 위치를 기준으로 정해집니다.

## 최종 확인

인코딩된 파일의 전체 디코딩에 성공했습니다. 144프레임, 12초, 초당 12프레임, 640 × 640, 오디오 트랙 없음이 확인됐습니다. 4초에 어두워지고 6초에 다시 밝아지는 전환을 실제 출력 프레임에서 검사했습니다. 시작·소등·재점등·이동 중간·마지막 프레임의 구도를 확인했으며, 마지막의 지붕과 오른쪽 문 일부 잘림은 의도한 가까운 구도입니다. 원본 장면의 해시가 바뀌지 않았습니다.
