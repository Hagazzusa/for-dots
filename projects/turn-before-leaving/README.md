# 떠나기 전에 한 번

밟고 있는 칸의 화살표를 돌리고 떠나는 1인용 종이 퍼즐 세 문제입니다. 지나온 칸은 처음과 다른 방향을 가리킬 수 있습니다. 같은 칸으로 돌아가는 행동이 다음 길을 만듭니다.

**수학적 풀이를 확인한 종이 퍼즐 시제품**입니다. 실제 인쇄·말을 사용한 플레이테스트와 체감 난이도는 아직 확인하지 않았습니다.

- [문제지 4쪽](output/pdf/Before-You-Leave.pdf): 세 문제와 재사용 판·자르는 화살표 조각
- [해설 3쪽](output/pdf/Before-You-Leave-Solutions.pdf): 최단 이동수와 단계별 선택
- [규칙과 문제 데이터](puzzles.json) · [검사 요약](qa.json)

## 규칙

1. 말 하나를 왼쪽 아래 A3에 놓습니다. 오른쪽 위 C1에 들어가면 끝입니다.
2. 움직이기 전에 **현재 칸**의 화살표를 그대로 두거나 시계방향으로 90도 딱 한 번 돌립니다. 그 방향으로 한 칸 이동합니다.
3. 바뀐 화살표는 그 칸에 그대로 남습니다. 다음에 돌아와도 초기 방향으로 되돌리지 않습니다.
4. 회전은 전체 합계 다섯 번까지만 가능합니다. 같은 칸을 다시 돌릴 때도 한 번을 씁니다.
5. 판 밖으로 이동하는 선택은 불법입니다. 회전만 하고 그 자리에 머물거나, 한 이동에서 두 번 돌릴 수 없습니다.
6. 막히면 처음 판과 회전 사용량 0으로 돌아가 다시 시도합니다. 먼저 도착을 찾고, 원하면 더 적은 이동을 찾아보세요.

종이에 3×3 판을 연필로 옮겨 그린 뒤 방향을 지우고 고쳐도 됩니다. 문제지 4쪽의 빈 판과 화살표 조각을 쓰면 각 조각을 돌려 상태를 표시할 수 있습니다. 목표 칸에는 화살표를 놓지 않으며 조각 하나는 여분입니다. 말을 대신할 작은 물건 하나가 더 필요합니다.

A4·실제 크기 100%로 인쇄하면 판 한 칸은 31.75mm, 조각은 약 24.69mm입니다. 맞춤 인쇄로 배율을 바꾸어도 규칙은 같지만 두 페이지를 같은 배율로 출력해야 조각이 판에 맞습니다. 가위를 사용할 때 주의하세요.

## 구성

- **돌려서 출발:** 가장자리에서 처음 방향을 바꾸고 출발합니다.
- **돌아오면 다른 방향:** 같은 칸으로 돌아오면서 방향을 차례로 바꿉니다.
- **바뀐 길 다시 쓰기:** 초반에 바꾼 길을 뒤쪽 우회에서 다시 사용합니다.

일반적인 방향 이동·회전 규칙을 조합한 직접 구성 문제입니다. 최초로 발명한 퍼즐 규칙이라고 주장하지 않습니다. 고정 난수 시드로 후보를 만들고 유일한 최단 선택열과 재방문을 기준으로 골랐습니다. `select_puzzles.py`로 같은 세 판을 다시 선택할 수 있습니다.

## 풀이와 검사

`solve.py`는 위치·아홉 화살표 방향·사용한 회전 수를 모두 상태에 넣고 너비 우선 탐색합니다. `independent_check.py`는 이 풀이 코드를 읽거나 가져오지 않고 작성한 별도 검사입니다. 좌표식 전이와 이진 선택열 직접 재생을 사용합니다. [독립 검사 설명](INDEPENDENT_VERIFICATION.md)에 범위와 한계가 있습니다.

세 시작점에서 목표 도착을 종료 상태로 한 도달 상태는 합계 70개, 유효 전이는 87개였습니다. 모든 전이를 두 구현으로 대조했습니다. 각 최단 선택열 수와 해설의 이동·회전 수도 일치했습니다. 해설의 수치는 사람에게 얼마나 어려운지에 대한 평가가 아닙니다.

최종 문제지·해설의 일곱 쪽을 모두 렌더해 확인했습니다. 글자 경계·가로 겹침·쪽 번호·한글 글꼴 내장과 문제·해설의 판 방향을 점검했습니다. 종이 조각의 실제 사용성은 미확인입니다.

## 재현과 보존

풀이에는 Python 표준 라이브러리만 필요합니다. PDF에는 ReportLab·fontTools·Noto Serif CJK Regular TTC, 검사에는 pdfplumber·pypdf가 필요합니다. 글꼴 배포 고지는 [FONT_LICENSE.txt](FONT_LICENSE.txt)에 있습니다. 원본 글꼴은 동봉하지 않으며 PDF에 사용 문자 부분집합을 내장합니다.

기존 결과를 덮어쓰지 않도록 별도 사본에서 실행합니다.

```sh
python3 select_puzzles.py
python3 solve.py
python3 independent_check.py
python3 build_pdf.py
python3 verify.py
```

`select_puzzles.py`는 후보를 표준출력에만 쓰고, `independent_check.py`와 `verify.py`의 기본 실행은 읽기 전용입니다. `solve.py`는 `solutions.json`, `build_pdf.py`는 PDF 두 파일을 생성합니다. PDF만 다른 경로에 만들 때는 `--output-root /tmp/arrow-puzzle-check`를 사용할 수 있습니다.

제작 코드·입력만 옮긴 별도 사본에서 해법 JSON과 PDF 두 파일이 바이트까지 동일하게 재생성되었습니다. 같은 설치 환경에서의 결과이며 다른 버전에서의 동일성을 보장하지 않습니다. `manifest.json`은 자신을 제외한 보존 파일의 크기·SHA-256을 기록합니다. 캐시·임시 페이지 렌더는 포함하지 않습니다.
