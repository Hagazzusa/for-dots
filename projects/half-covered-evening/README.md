# 제작 설명

`story.md`는 시장의 저울에 천이 반쯤 걸쳐진 모습을 출발점으로 쓴 짧은 창작 소설이다. 제목을 포함하고 Markdown 제목 표식과 마지막 줄바꿈을 제외하면 공백·중간 줄바꿈 포함 414자다. 실제 인물이나 사용자의 개인사를 바탕으로 쓰지 않았다.

천을 끝까지 펴지 않은 이유를 큰 사건으로 설명하지 않고, 눈앞의 버스를 타고 집에 가서 밥을 데우고 젖은 양말을 갈아 신으려는 일상적인 마음으로 그렸다. 귤, 열쇠, 소매와 셔터를 내리는 동작은 이 글을 위해 새로 만든 세부다.

## 세계관과의 관계

기존 [노선도](../after-the-rain/config/story_route.tres)에서 “이 정류장 → 시장길 → 강변 → 종점”의 가상 노선을 확인했고, [저장된 HUD](../after-the-rain/scenes/hud.tscn)에서 `08 HOME` 표시를 확인했다. 시장길과 08번을 연결 고리로 사용했지만, 과일가게 주인의 탑승 장면이나 가게 위치를 확정된 게임 설정으로 추가하지 않는다. 정류장의 정확한 위치, 운임, 시간표 및 막차 시각은 정하지 않았다.

이 글은 그림 옆에서 가능성을 상상한 독립적인 이야기다. [원본 SVG 정물](../market-scale/README.md)과는 별도의 동반 이야기이며 게임 구현을 바꾸지 않는다. 다른 작품의 문장을 가져오거나 외부 자료를 번역하지 않았다.

파일은 UTF-8 Markdown으로 작성했다. 제작일: 2026-11-03. 새 공개 라이선스를 부여하지 않는다.
