# 프로젝트 경로 정리 검증 기록 · 2026-11-05

이 문서는 [이전 정리 커밋 01938507](https://github.com/Hagazzusa/for-dots/tree/01938507)에서 수행한 검사의 역사적 기록입니다. 아래 보존 상태와 검사 결과는 그 시점에 한정되며, 현재 폴더 구성이나 이번 전체 이관 후의 재검사 결과를 뜻하지 않습니다.

현재는 모든 65개 프로젝트를 `projects/`로 통합했고, 기존 최상위 프로젝트 폴더와 `creative-work-2026-11-05/` 날짜 보관본은 제거했습니다. 역사적 파일·검사 결과는 Git 이력에서 확인할 수 있습니다. 기존 작품의 미적·기술적 검토를 새로 수행했다고 주장하지 않습니다.

## 이전 커밋에서의 보존과 문서

- 기존 최상위 작품은 이동하거나 수정하지 않았습니다.
- 날짜 보관본의 작품·코드·매니페스트 바이트는 그대로 유지했습니다. 보관본 README 앞에 현재 정식 경로 안내만 추가했습니다.
- 정식 프로젝트의 이미지·영상·음원·PDF·Blender 장면은 보관본과 같은 바이트를 사용합니다. 문서, 상대 의존 경로와 검사 매니페스트를 정리했습니다.
- 루트 안내·갤러리·새 프로젝트의 Markdown 상대 링크와 파일 존재를 확인했습니다. 기존 영문 예외와 라이선스 원문은 유지했습니다.
- 원작을 읽는 원 실험의 형제 경로를 수정했습니다. 미리보기 캐시가 없으면 새 코드의 생성 기록을 작성하고, 캐시가 있는데 코드 해시가 다르면 이전 프레임과 섞지 않도록 중단합니다. 기존 생성 기록을 새 코드의 렌더 기록인 것처럼 바꾸지 않았습니다.
- 세 PDF 프로젝트에는 처음 실행할 때 필요한 `tmp/pdfs`·`output/pdf` 생성 명령을 추가했습니다.

## 이전 커밋에서 실제로 실행한 검사

원본을 덮어쓰지 않도록 별도 사본에서 재생성했습니다.

- Python 소스 45개 구문 검사.
- PNG 8개 디코딩, PDF 7개·총 26쪽 열기.
- PDF·벡터 프로젝트 6개 재생성과 전용 검사 통과: 《한 줄의 바깥》, 《확인 중》, 《길을 남기는 일》, 《맨 앞》, 《옮기는 동안》, 《고객 역할》. 퍼즐의 별도 해답 열거 검사도 통과했습니다.
- 《다시 만나는 박자》 재생성. WAV·MP3·악보 JSON은 배포본과 바이트 단위로 일치했습니다.
- MP4 3개와 MP3·WAV 전체 디코딩.
- Blender 4.3.2에서 장면 8개를 직접 열었습니다. 외부 파일 이미지에 의존하지 않는 것을 확인했습니다.
- 《여덟 칸의 여유》, 《한 자리에서만 원》, 《각자의 수평》의 저장 장면 전용 검사 통과.
- 《원을 지나서 돌아오기》의 원작 대비 비카메라 내용 일치, 384개 프레임의 고정 카메라 높이·렌즈, 시작·끝 카메라 상태 일치 검사 통과.
- 미리보기 캐시가 없는 경우, 현재 코드와 일치하는 경우, 오래된 코드와 불일치하는 경우의 세 분기 검사 통과.
- 《문턱에 남은 빛》 영상의 길이·프레임 수와 조명 전환 검사 통과.
- 공개 전 패턴 검사에서 자동 검사 대상의 비공개 경로·자격 증명 패턴 탐지는 없었습니다. 미지원 바이너리는 별도 장면 열기·PDF/미디어 메타데이터 확인을 했습니다. 이는 완전한 개인정보 탐지나 보안 인증이 아닙니다.

## 이전 검사에서 하지 않은 것과 재현 조건

- 이번 정리에서 새 시각 감상·청취 검토, 전체 3D 정지 렌더 또는 애니메이션 재렌더는 하지 않았습니다. 각 프로젝트의 기존 QA는 당시 제작 검토 기록입니다.
- 원 실험의 중간 프레임은 배포에서 제외했습니다. 원본 첫·마지막 프레임의 바이트 비교는 `preview/`를 재생성해야 실행할 수 있으며, 이번에는 저장 장면 검사만 별도로 수행했습니다.
- PDF 재생성은 본문·페이지와 전용 검사를 확인한 것이며, 날짜 메타데이터 등을 포함한 전체 PDF 바이트 일치를 주장하지 않습니다.
- Blender 검사에서 처음 실행한 프로세스가 종료돼 스레드를 제한한 뒤 재시도했습니다. `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1`과 `-t 1`로 장면 열기가 완료됐습니다. 전체 렌더의 성능이나 다른 환경에서의 결과 일치를 보장하지 않습니다.

해당 커밋의 추적 파일 크기·SHA-256은 해당 시점의 루트 `SOURCE_MANIFEST.json`과 `python3 verify_sources.py`로 확인합니다. 당시 프로젝트별 매니페스트는 그때 제공한 파일에 맞춰 갱신했으며 비공개로 제외된 계획·검토 문서는 포함하지 않습니다.
