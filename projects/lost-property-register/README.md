# 저녁 분실물 접수장

접수대 불을 끄기 전에 오늘의 마지막 네 줄을 옮겨 적는다. 빗물에 번진 기록에서 시각만 읽힌다. 다행히 두고 간 쪽지에는 몇 가지가 더 적혀 있다.

- **접수 시각** · 17:00, 17:10, 17:20, 17:30
- **물건** · 열쇠, 수첩, 목도리, 우산
- **발견 장소** · 빵집, 놀이터, 작은도서관, 자전거 가게

네 장소에서 물건이 하나씩 발견됐고, 네 시각에 하나씩 분실물 보관소에 들어왔다. **발견 장소**는 물건을 주운 곳, **접수 시각**은 보관소에 들어온 시각이다. 각 시각에 어떤 물건이 어디에서 왔는지 맞혀 보자.

### 남은 쪽지

1. 수첩은 목도리보다 정확히 10분 먼저 접수됐다.
2. 작은도서관에서 주운 물건은 빵집에서 주운 물건보다 정확히 20분 늦게 접수됐다.
3. 자전거 가게에서 주운 물건은 놀이터에서 주운 물건보다 늦게 접수됐다.
4. 열쇠는 수첩보다 먼저 접수됐다.
5. 우산은 자전거 가게에서 발견됐다.
