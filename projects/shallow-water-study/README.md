# 얕은 물 · 두 가지 분리 시험

각 기준 장면에서 독립 복사본을 만들고 **각각 한 장만** 저비용으로 렌더했다. 완성 작품이 아닌 제한된 연구 기록이다. 낮은 카메라 시험은 실행하지 않았다.

## 실제 비교 이미지

두 패널 모두 **왼쪽이 자기 기준, 오른쪽이 해당 시험**이다. 원본 이미지에서 같은 좌표·같은 크기의 부분을 잘라 나란히 놓았으며 색이나 밝기를 수정하지 않았다.

- `dish/same_crop_comparison.png`: 접시의 마지막 광원 이동본과 경계 수정본.
- `puddle/same_crop_comparison.png`: 물웅덩이의 Nishita 강도 0.1 기준과 0.4 시험.
- 각 폴더의 `comparison.png`: 잘라내지 않은 해당 시험의 실제 렌더.

## 1. 접시: 교차를 없애도 중앙은 여전히 어둡다

기준은 평평한 수면 셰이딩과 옮긴 광원이 있는 `baseline/dish.blend`다. 800×800, 32샘플, 시드 28, 카메라·AgX·바운스·노이즈·재질·광원을 유지했다.

전체 반지름을 1%씩 줄이는 단순 기하 탐색에서는 10% 축소까지도 낮은 경계의 교차가 남아, 이 후보들은 렌더하지 않았다. 대신 평가된 그릇 내면을 33개 고정 높이 × 192개 방향으로 조회해, 기존 물 경계보다 바깥으로 나가지 않으면서 그릇 안쪽에 **수평 0.25 mm 이상의 인공 공기 틈**을 두었다. 바닥/수면 높이는 그대로다. 저장본을 다시 열어 수면의 외곽 정점이 원본과 정확히 같고, 192개 윗면이 모두 평면 셰이딩임을 확인했다.

- 평가된 삼각형 표면의 BVH 교차 후보: **0**.
- 양방향 선분–삼각형 교차: **0**. 수치 메시 검사이지 정확한 CAD 증명은 아니다.
- 33개 높이·192방향의 수평 틈 표본(전체 표면 최소 간격 아님): **0.250–0.514 mm**.
- 옆면 정점에서 그릇 표면까지의 최근접 거리 표본: **0.0127–0.2230 mm**. 경사면이므로 수평 틈과 다른 값이다.
- 기존 옆 경계에서 안쪽으로 이동한 거리: **0–3.612 mm**.

고정된 중앙 표본의 표시 밝기 평균은 **37.01→37.45/255**다. 차이는 0.44이며 같은 표본의 픽셀 차이 표준편차는 3.98이다. 이 작은 중앙 변화로 원인을 결론내리지 않는다. 별도 시드 반복으로 Monte Carlo 노이즈를 추정하지 않았으므로 “통계적으로 유의하다/없다”는 주장도 하지 않는다.

가장자리에는 새로운 밝고 불연속적인 띠가 보인다. 따라서 경계 기하가 가장자리 영상에 영향을 준다는 관찰은 남지만, **교차 제거와 인공 공기 틈·경계 재테셀레이션의 영향을 분리할 수 없다**. 물리적인 최종 접촉 모델이 아니며 가장자리 외관 개선의 증거로 채택하지 않는다. 중앙 어두움 전체의 원인은 미확정이다.

## 2. 물웅덩이: 환경 영향은 크지만 반사 단서가 더 명료해지지는 않았다

기준은 `baseline/puddle.blend`와 `baseline/puddle.png`다. 600×400, 24샘플, 시드 59, 카메라·물·지면·태양광·AgX·바운스·노이즈 설정을 유지했다. **World Background 강도만 0.1→0.4**로 바꿨다. 모든 메시 해시는 그대로다.

고정 표본의 8비트 표시 밝기 평균:

| 표본 | 기준 0.1 | 시험 0.4 |
|---|---:|---:|
| 왼쪽의 어두운 수면 | 42.95 | 111.41 |
| 중앙 반사 영역 | 62.61 | 122.20 |
| 앞쪽 지면 | 106.56 | 159.01 |

어두운 수면/지면 밝기 비율은 **0.403→0.701**로 바뀌었다. 따라서 단순히 모든 픽셀이 똑같이 밝아진 것은 아니다. 그러나 중앙 반사 영역과 옆 수면 사이 평균 차이는 **19.66→10.79**로 작아졌으며, 실제 비교에서도 반사 패턴이 더 명료해졌다고 보기 어렵다. 수면은 밝고 푸르게 변했지만 여전히 얼룩 같은 덩어리로 읽힐 수 있다. 밝아졌다는 것만으로 목표를 달성했다고 하지 않는다.

이 변화는 수십 밝기 단계로 관찰되며 미세한 잡음만의 변화처럼 보이지 않는다. 다만 월드는 지면 조명도 바꾸므로, 물의 밝아짐을 순수 반사 기여율로 분해하거나 특정 광학 원인 하나로 환산할 수 없다. 관객 대상 인지 실험도 하지 않았다.

## 기록과 한계

- `run_test.py`: 원본을 읽고 각 독립 복사본에서 한 범주만 바꾸는 코드.
- `dish/test_validation.json`, `puddle/test_validation.json`: 원본 해시, 고정 설정, 기하·변경 범위 기록.
- `dish/top_boundary_validation.json`: 재개방 후 윗면 경계·높이·평면 셰이딩 비교.
- `comparison_metrics.json`, `compare.py`: 고정된 화면 좌표의 표시 밝기 통계와 동일 크롭 비교 제작.
- `baseline/`: 재현 입력인 두 기준 장면과 기준 PNG. 생성되는 `Test.blend`는 배포하지 않는다.

수치는 감마·톤매핑이 적용된 PNG의 표시 밝기이며 선형 방사량, 물의 실제 반사율 또는 정확한 광원 기여도가 아니다. 같은 시드를 써도 기하나 조명이 바뀌면 샘플 경로와 분산이 달라질 수 있다. 접시의 작은 중앙 변화는 판정 유보, 물웅덩이는 환경 영향만 확인하고 목표 달성은 유보한다. 추가 렌더나 고샘플 최종화로 실패를 감추지 않고 여기서 멈춘다.

## 공개 사본과 재현

Blender 4.3.2, Python의 Pillow·NumPy가 필요하다. 원본 절차형 형상·재질을 만든 독자 연구이며 외부 사진·메시·텍스처를 사용하지 않았다. 물웅덩이의 초기 구상에는 생성 이미지가 참고되었지만 실제 장면의 텍스처나 이 시험의 입력은 아니다. 이 묶음에는 생성 콘셉트와 로그를 포함하지 않는다. 새로운 공개 이용 라이선스를 부여하지 않는다.

이 배포는 **동결된 기준 장면에서 두 변형을 다시 만드는 범위**다. 최초 장면을 빈 파일부터 만드는 생성기 전체를 포함하지 않는다. 제공된 기준 PNG와 기존 시험 PNG가 관찰 증거다. Blender 버전·장치·라이브러리가 달라지면 렌더 바이트까지 같다고 보장하지 않는다.

폴더 전체를 새 작업 사본으로 복사한 뒤 실행한다. 각 첫 명령은 기준 장면을 읽고 해당 `dish/` 또는 `puddle/`의 `Test.blend`, `comparison.png`, `test_validation.json`을 덮어쓴다. 기준 장면과 기준 PNG는 쓰지 않는다. `check_top.py`는 `dish/top_boundary_validation.json`을, `compare.py`는 두 크롭 PNG와 `comparison_metrics.json`을 덮어쓴다. 따라서 어느 명령도 파일시스템 전체의 읽기 전용 검사는 아니다.

```sh
blender --background --disable-autoexec --threads 2 --python-exit-code 1 --python run_test.py -- dish
blender --background --disable-autoexec --threads 2 --python-exit-code 1 --python run_test.py -- puddle
blender --background --disable-autoexec --threads 2 --python-exit-code 1 --python check_top.py
python3 compare.py
```

PNG 네 장의 작업 경로 텍스트만 공개 사본에서 제거했으며 IDAT와 디코딩 픽셀은 동일하다. 두 기준 장면의 저장 출력·브라우저 경로는 상대화했다. 장면 내용 비교는 객체·변환·메시·재질·modifier 설정·카메라·조명·월드 노드·Cycles·색 관리 설정을 대상으로 했으며 저장 세션 식별자는 제외했다. 원래 파일 해시와 공개 사본 해시는 `provenance.json`에서 구분한다. 기존 수치 보고서의 측정값은 바꾸지 않고 입력 위치·사본 해시만 갱신했다.

### 이번 공개 사본의 재실행 확인

별도의 작업 복사본에서 Blender 4.3.2 CPU 2 threads로 접시32·물웅덩이24 samples를 각각 한 번 다시 렌더했다. 두 시험의 RGBA 픽셀과 크롭 결과, 고정 영역 통계가 보존된 결과와 동일했다. 접시 윗면 재개봉 검사도 다시 통과했다. 이는 같은 환경의 동작·재현 확인이지 다른 시드 반복, 통계적 신뢰도 추정 또는 다른 장치의 바이트 동일성 보장이 아니다. 새 렌더는 원래 관찰 증거를 대체하지 않았다.
