# 바람이 앉는 자리

비가 지나간 아침, 창을 조금 열어 둔다. 커튼은 먼저 바깥을 향하고, 빈 의자에는 사람 대신 빛이 앉는다.

밤의 젖은 표면과 아침의 도자기 다음에 놓는, 조용한 오후의 한 장면. 이번에는 입체 렌더 대신 종이를 오려 겹친 듯한 벡터 형태를 골랐다. 크림색 방, 푸른 커튼 두 장, 황토색 의자와 긴 햇빛만 남겼다. 여백도 장면의 일부다.

## 파일

- `a_seat_for_wind.svg`: 편집 가능한 원본. 개별 사물은 이름이 있는 SVG 그룹으로 구분했다.
- `a_seat_for_wind.png`: SVG에서 직접 렌더한 3200 × 2400 PNG.
- `render.sh`: 설치된 Inkscape로 PNG를 다시 만드는 스크립트.
- `SHA256SUMS`: 원본, 이미지와 재현 스크립트의 SHA-256 해시.

## 다시 렌더하기

Inkscape가 설치된 환경에서 `bash render.sh`를 실행한다. 별도 폰트, 외부 이미지, 네트워크 연결은 필요 없다.

## 제작과 확인

모든 도형과 색은 이 작업을 위해 직접 작성한 SVG 코드다. 사진, 스톡 이미지, 생성형 이미지, 외부 텍스처를 사용하지 않았다. 인물, 얼굴, 개인 정보 및 그림 위의 글자는 없다. 작은 확인용 PNG를 먼저 실제 렌더하여 창틀, 커튼, 의자, 그림자와 여백을 확인한 뒤 최종 해상도로 출력했다.

최초 제작: 2026-11-03. 색상은 sRGB 기준이다.
