# 반대편으로 한 칸

A와 B를 반대 방향으로 함께 움직이는 1인용 종이 퍼즐 세 문제입니다. 벽에 한 말이 멈추는 동안 다른 말은 계속 움직일 수 있습니다. 동전처럼 서로 구별할 수 있는 작은 말 두 개를 준비하면 됩니다.

[문제지 PDF](output/pdf/Opposite-Steps.pdf) · [해설 PDF](output/pdf/Opposite-Steps-Solutions.pdf)

## 규칙

1. 위·오른쪽·아래·왼쪽 중 하나를 고릅니다. 이 방향은 항상 A 기준입니다. A는 그쪽으로 한 칸, B는 반대쪽으로 한 칸 움직이려 합니다.
2. 각 말의 이동 예정 칸을 먼저 정합니다. 벽이나 판 밖으로 나가려는 말의 예정 칸은 현재 칸으로 바꿉니다.
3. 그 결과 두 예정 칸이 같거나 서로의 현재 칸을 맞바꾸게 되면 둘 다 제자리입니다. 그 밖에는 예정 칸으로 함께 이동합니다.
4. 목적지에 먼저 도착한 말도 계속 움직입니다. A와 B가 각각 자기 목적지에 동시에 놓이면 성공입니다.

처음에는 횟수 제한 없이 도착해 보세요. 최소 횟수는 해설에 있습니다.

## 세 문제의 구성

- **한쪽이 멈추면:** 한 말이 벽에 막혀 있는 동안 다른 말이 목적지에 도착합니다.
- **지나갔다 돌아오기:** 첫 문제와 같은 벽이지만 목적지가 다릅니다. 최단 해법에서는 두 말 모두 자기 목적지를 먼저 지나친 뒤 돌아옵니다.
- **벽 하나가 더:** 벽을 하나 추가했습니다. 최단 해법에서는 멈추는 말이 A에서 B로 바뀝니다.

이 설명은 각 문제의 유일한 최단 명령열에서 확인한 사건입니다. 모든 우회 해법의 필수 순서라고 주장하지는 않습니다. 더 긴 해법도 정답입니다.

## 원본과 재현

- `puzzles.json`: 판, 출발점, 목적지.
- `solve.py`, `solutions.json`: 너비 우선 탐색과 최단 상태열.
- `independent_check.py`, `independent_check_results.json`, `INDEPENDENT_CHECK.md`: 별도 좌표 구현의 검증과 설명.
- `verify.py`, `qa.json`: 모든 유효 상태의 이동 대조와 해법 검사.
- `build_pdf.py`, `layout.json`, `output/layout_manifest.json`, `verify_pdf.py`, `qa_layout.json`: 문제지·해설 제작, 출력 구성 기록과 조판 검사.
- `manifest.json`: 보존 대상의 파일 크기와 SHA-256.

원본을 보존하려면 별도 사본에서 실행합니다.

```sh
python3 solve.py
python3 verify.py
python3 independent_check.py
python3 build_pdf.py
python3 verify_pdf.py
```

기본 검사 명령은 보존 파일을 바꾸지 않습니다. PDF 검사 보고서를 따로 저장하려면 `--report 파일명.json`을 지정합니다.

풀이 검사는 Python 표준 라이브러리만 사용합니다. PDF 제작·검사 의존성은 제작 코드의 설명을 참고하세요. 글꼴은 Noto Serif CJK KR이며 SIL Open Font License 1.1에 따라 PDF에 부분집합을 포함합니다.

## 확인한 범위

두 구현으로 최단 횟수 3·7·11회와 각 최단 명령열 한 개를 확인했습니다. 세 판의 모든 유효 상태에서 가능한 이동 2,408개를 두 구현으로 대조했습니다. 해설의 상태열도 이동 규칙과 일치합니다. PDF는 모든 페이지를 렌더해 확인하고 별도 사본의 재생성 결과를 비교했습니다.

실제 인쇄·말을 사용한 플레이테스트는 진행하지 않았습니다. 수학적 해법 검증과 사람의 재미·난이도 평가는 다릅니다. 인쇄할 때는 A4, 실제 크기 100%를 권합니다. 퍼즐 성립은 인쇄 배율에 의존하지 않지만, 사용하려는 말이 칸 안에 들어가는지 확인해 주세요.
