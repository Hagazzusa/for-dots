# 독립 검증 결과

`independent_check.py`는 `solve.py`를 가져오지 않는 별도 좌표 기반 구현입니다. `puzzles.json`을 읽어 너비 우선 탐색으로 시작점에서 도달 가능한 모든 상태를 조사하고, 최단 명령열의 수를 계산하며, 최단 경로 하나를 복원합니다. 상태가 바뀌지 않는 명령은 최단 경로에 포함될 수 없습니다. 기본 이동 규칙 테스트 5개를 통과했습니다.

프로젝트 폴더 안에서 실행합니다.

```sh
python3 independent_check.py
```

전체 계산 결과와 매 이동 후 상태는 `independent_check_results.json`에 있습니다.

## 문제별 결과

- **1번:** 목표에 도달할 수 있으며 최단 **3수**, 최단 명령열 **1개**, 시작점에서 도달 가능한 상태 **86개**입니다. 명령은 위 / 오른쪽 / 아래입니다. 3수째 B가 벽 2에 막혀 자기 목표인 6번 칸에 머무는 동안 A가 13번 칸에 도착합니다. 한쪽 말만 멈추는 원리를 직접 보여 줍니다.
- **2번:** 목표에 도달할 수 있으며 최단 **7수**, 최단 명령열 **1개**, 도달 가능한 상태 **86개**입니다. 명령은 위 / 오른쪽 / 오른쪽 / 아래 / 왼쪽 / 위 / 왼쪽입니다. A는 1수째 목표인 8번 칸에, B는 2수째 목표인 6번 칸에 처음 도착한 뒤 각각 그 칸을 떠납니다. 7수째 두 말이 함께 돌아옵니다. 5수째에는 B가 벽 2에 막힙니다. 유일한 최단 해법에서 두 말 모두 목표를 지나갔다 돌아오는 흐름이 성립합니다.
- **3번:** 목표에 도달할 수 있으며 최단 **11수**, 최단 명령열 **1개**, 도달 가능한 상태 **144개**입니다. 명령은 위 / 위 / 위 / 오른쪽 / 아래 / 왼쪽 / 아래 / 아래 / 오른쪽 / 오른쪽 / 위입니다. 5수째 A가 벽 5에 막혀 1번 칸에 머무는 동안 B가 움직입니다. 이후 9·10수째에는 B가 벽 2에 막혀 3번 칸에 머무는 동안 A가 움직입니다. 의도한 대로 멈추는 말이 교대합니다. B는 앞서 1수째와 7수째에도 목표인 7번 칸을 방문하지만 다시 떠났다가 11수째 돌아옵니다.

## 검증 범위와 한계

세 문제의 해법 명령열은 독립 구현으로 복원한 경로와 모두 일치합니다. 위에서 설명한 특징은 각 문제의 유일한 최단 해법에서 확인했으며, 더 긴 모든 해법에서도 반드시 나타난다고 주장하지 않습니다. 이번 검증 결과에 따른 문제판 수정은 필요하지 않습니다.

사람을 대상으로 한 플레이테스트는 아직 진행하지 않았습니다. 수학적으로 풀 수 있고 의도한 원리가 단계적으로 등장한다는 검증을, 재미나 난이도 조절까지 검증한 것으로 설명해서는 안 됩니다.
