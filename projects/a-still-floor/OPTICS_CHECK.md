# A Still Floor: 굴절 모델 점검

## 결과와 범위

최종 6파형 모델에서 **10개 검사 항목이 모두 통과**했다. 검사 대상은 `model.json`과 `build.py`의 수치적 자기일관성이다. 실제 물의 실험 검증, 유체 방정식의 해 검증 또는 수중 실사 재현의 검증은 아니다. 검사한 파일의 SHA-256과 전체 수치는 `optics_qa.json`에 남긴다.

현재 모델은 가로·세로 6의 주기 영역, 평균 수면 아래 깊이 2.2의 바닥, 공기 굴절률 1.0과 물 굴절률 1.333을 사용한다. 길이는 모델 내부 단위이며 실제 미터 규모로 보정하지 않았다. 흐림의 표준편차는 2.0픽셀이다. 정지화상은 768×768픽셀에 1536²개 광선, 영상은 512×512픽셀에 프레임당 768²개 광선을 사용한다. 이 검사에서는 메모리를 아끼기 위해 더 작은 격자만 사용했다.

## 어떤 모델인가

수면은 다음 그래프다.

`h(x,y,t) = Σ a_j cos[2π(n_xj x + n_yj y)/L + 2π c_j t/T + φ_j]`

여기서 `L=6`, `T=10초`다. 파수와 시간 반복 횟수가 정수이므로 높이와 기울기, 그로부터 정해지는 굴절 방향과 바닥 교차점은 공간과 시간에 대해 주기적이다. 서로 다른 방향의 코사인파 여섯 개를 합한 작화용 수면이다. 분산 관계, 압력, 중력, 수심에 따른 파속을 푼 유체 시뮬레이션이 아니다.

입사 방향은 `I=(0,0,-1)`, 공기 쪽 단위 법선은 `N=(-h_x,-h_y,1)/√(1+h_x²+h_y²)`다. `η=n_air/n_water`, `c_i=N_z`일 때 제작 코드는 다음 굴절 방향을 사용한다.

`T_ray = η I + [η c_i − √(1−η²(1−c_i²))] N`

검사 코드는 이 식을 복사해 정답으로 삼지 않는다. 스칼라 높이식을 별도로 계산하고 중앙 유한차분으로 기울기를 얻는다. 이 법선에 대해 `sin θ_t = (n_air/n_water) sin θ_i`를 적용한 뒤, 법선과 입사면 접선 성분을 합쳐 별도의 굴절 광선을 만든다. 제작 함수의 결과를 이 기준과 비교한다.

바닥 `z=−d`까지의 전파 거리는 `s=(−d−h)/T_ray,z`이고, 교차점은 `(x,y,h)+s T_ray`다. 검사는 `s>0`, `T_ray,z<0`, 바닥의 z좌표, 독립 계산한 x·y좌표를 확인한다. 진폭 절댓값의 합이 0.36이므로 바닥과 수면의 간격은 전 영역에서 최소 1.84다.

## 검사와 주요 수치

- 고정 난수 표본 257개를 5개 시각에서 검사했다. 높이의 최대 차이는 `8.88×10⁻¹⁶`, 유한차분 기울기의 최대 차이는 `1.66×10⁻¹⁰`이었다. 차분 간격은 `10⁻⁵`다.
- 법선과 굴절 방향의 단위 길이 오차는 각각 최대 `2.22×10⁻¹⁶`이었다. 모든 표본이 유한하며 물 안쪽·아래쪽을 향했다. 표본 중 가장 큰 z방향 성분도 `−0.9845`였다.
- `n_air sin θ_i − n_water sin θ_t`의 최대 오차는 `2.22×10⁻¹⁶`이었다. 접선 성분 관계도 별도로 검사해 잘못된 접선 방향을 배제했다.
- 독립 각도식과 제작식의 방향 차이는 최대 `3.95×10⁻¹¹`, 바닥 위치 차이는 최대 `8.63×10⁻¹¹`이었다. 바닥 z좌표 잔차는 최대 `4.44×10⁻¹⁶`이었다.
- 10초 전후의 방향 차이는 최대 `4.09×10⁻¹⁶`, 바닥 위치 차이는 최대 `8.88×10⁻¹⁶`이었다. 중앙 차분으로 구한 바닥 교차점 이동속도의 차이도 `4.44×10⁻¹²` 이내였다.
- x 또는 y를 6만큼 이동했을 때 수면·방향이 반복되고, 감싸기 전 바닥 위치는 같은 만큼 이동했다. 위치의 최대 오차는 `2.66×10⁻¹⁵`이었다.
- 파형을 모두 제거한 평탄 수면에서 광선은 정확히 수직으로 내려갔다. 64²개 광선을 32²개 픽셀에 배치한 밀도는 수치 오차 내에서 모든 픽셀이 1이었다.
- 17², 33², 65², 130²개 광선과 서로 다른 픽셀 격자를 3개 시각에서 검사했다. **12개 경우 모두 광선 개수가 정확히 보존**되었고, 흐림 후 정규화 평균의 오차는 최대 `2.22×10⁻¹⁶`이었다. 16행 타일의 마지막 불완전 묶음도 포함한다.
- 별도의 스칼라 광선 4225개를 한 개씩 집계하고, SciPy를 호출하지 않는 주기 가우스 합과 비교했다. 이 중 125개는 영역 경계를 넘어 반대편으로 감쌌다. 최종 밀도의 최대 차이는 `6.66×10⁻¹⁶`이었다.

가장 큰 검사 광선 격자는 130×130, 밀도 배열은 64×64다. 큰 출력 영상을 다시 렌더링하지 않는다. 제작 코드의 광선 묶음 계산을 그대로 호출하면서, 독립 기준은 작은 표본 또는 단일 광선 루프로 계산한다.

## 해석할 때의 한계

- 보존되는 것은 각 광선에 같은 가중치를 준 **광선 개수와 정규화 밀도 합**이다. 프레넬 반사 손실, 흡수, 파장별 굴절, 산란, 다중 반사, 회절·간섭을 포함한 실제 투과 에너지의 보존 검사가 아니다.
- 주기적 감싸기는 무한히 반복되는 타일 수면·바닥을 가정한다. 유한 수조의 벽을 재현하지 않는다.
- 가우스 흐림과 청록에서 옅은 금색으로 가는 색상 매핑은 작화 선택이다. 밀도 값은 평균 1의 상대값이며 측정된 절대 방사조도나 측정색이 아니다.
- 연속 기하 모델의 주기는 검사했지만, 압축 영상이나 최종 픽셀의 무이음성을 보증하지 않는다. 마지막 프레임 시각은 `T−1/fps`이며 첫 프레임을 마지막에 중복 저장하지 않는다. 최종 영상의 재생 품질은 별도로 확인해야 한다.
- 작은 격자와 표본 검사는 전체 출력 해상도의 모든 광선을 검사한 것이 아니다. 수치 허용오차와 검사 구현은 `verify_optics.py`에서 확인할 수 있다.

## 재실행

프로젝트 폴더에서 다음 명령을 사용한다. 기본 실행은 결과를 표준 출력에 표시할 뿐, 검사 보고서나 바이트코드 캐시를 쓰지 않는다.

```sh
python verify_optics.py
```

다음처럼 `--report`를 명시할 때만 지정한 JSON 파일을 갱신한다. 검사 실패 시 종료 코드는 1이다.

```sh
python verify_optics.py --report optics_qa.json
```

모델이나 제작 코드가 바뀌면 보고서를 다시 생성해야 한다. 이 문서의 수치는 최종 6파형·수심 2.2 모델의 기록이다.
