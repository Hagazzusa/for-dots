# 빛의 정원 · Garden of Light

책상 크기로 만든 독창적인 **가상** 조명 설치 작품입니다. 따뜻한 종이 전시대 위에 차분한 살구색, 안개빛 청록색, 탁한 보라색 필터 세 개를 세웠습니다. 빛은 작고 연속적인 궤도를 한 바퀴 돕니다. 섬광, 소리, 카메라 전환은 없습니다.

## 파일
- `Garden-of-Light.blend` — 편집 가능한 장면, 재질, 카메라, 키프레임 조명.
- `Garden-of-Light.png` — 800 × 800 정지 이미지.
- `Garden-of-Light-loop.mp4` — 480 × 480, 48프레임 / 12 fps, 4초 반복 영상.
- `build.py` — 이식 가능한 절차적 소스. 모든 지오메트리와 텍스처는 직접 제작했습니다.
- `validation_*.json` — 빌드에서 수행한 수치 검사.

## 다시 렌더링하기
Blender 4.3+와 영상 인코딩용 ffmpeg가 필요합니다. 다운로드나 외부 에셋은 필요하지 않습니다. 작업 디렉터리와 관계없이 소스 옆에 결과를 저장합니다.

```sh
blender -b -t 2 --python build.py -- --render still
blender -b -t 2 --python build.py -- --render loop
ffmpeg -framerate 12 -i frames/frame_%04d.png -c:v libx264 -crf 19 \
  -pix_fmt yuv420p -movflags +faststart Garden-of-Light-loop.mp4
```

정지 이미지는 Cycles CPU, 스레드 두 개, 64샘플을 사용하며, 반복 영상은 24샘플을 사용합니다. 시험한 Blender 빌드에 OpenImageDenoise가 없어 디노이징을 의도적으로 껐습니다. 미세한 몬테카를로 노이즈가 남을 수 있습니다. 반복 영상은 중복 끝점인 49프레임을 제외하고 1–48프레임을 인코딩합니다.

## 조명 모델의 의미
이것은 속이 찬 유리가 아니라 **얇고 굴절하지 않는 광학 필터의 근사 모델**입니다. 재질은 유색 투명 투과와 소량의 확산 표면 성분을 결합합니다. Cycles는 그 결과 나타나는 유색광 감쇠를 무광 전시대까지 추적합니다. 금속 테두리와 세라믹 받침은 일반적인 음영 지오메트리입니다. 분광 시뮬레이션, 코스틱 집광 시뮬레이션, 실물 제작 계획 또는 실제 재료 성능에 대한 보장이 아닙니다. 종이 질감은 절차적 노이즈로 미세한 표면 범프를 만듭니다.

장면의 단일 면광원은 출력을 일정하게 유지하면서 부드럽게 위치를 바꿉니다. 모든 패널, 카메라, 지오메트리는 고정되어 있습니다. 합성기로 그린 그림자, 투사 색상 데칼, 노출 애니메이션, 숨겨진 유색광은 없습니다.

## 검증한 결과
- 최종 정지 이미지와 애니메이션 6칸 비교 이미지를 확인했습니다. 비교 이미지는 `verify.py`로 다시 만들 수 있으며 이 체크포인트에는 포함하지 않았습니다.
- 비어 있지 않은 48프레임, 480 × 480 H.264 영상, 정확히 4초 길이입니다.
- 1프레임과 49프레임의 광원 변환 폐합 오차: **0.0**.
- 반복 경계의 평균 절대 RGB 변화: **0.001924**. 일반 인접 프레임 평균: **0.001934**. 반복 경계는 불연속 이상치가 아닙니다.
- 저장한 `.blend`를 다시 열어 오브젝트 13개, Cycles, 48프레임 타임라인, 상대 렌더 출력 경로, 외부 이미지 의존성 없음을 확인했습니다.
- `verify.py`는 반복 영상 렌더링 후 픽셀/영상 품질 검사를 다시 계산하며 Pillow, numpy, ffprobe가 필요합니다. 렌더 중간 산출물은 Git에서 제외합니다.

## 이식 가능한 체크포인트
PNG 메타데이터에서는 로컬 렌더 경로를 제외했으며 이미지 픽셀은 그대로입니다. 저장된 Blender 파일 탐색기 경로는 상대 경로입니다. 중간 프레임, 로그, 비교 이미지, 백업/캐시 파일은 제외했습니다. 모든 원본 지오메트리, 재질, 절차적 텍스처 계산은 직접 제작했으며 외부 미디어나 개인 정보가 필요하지 않습니다.
