# 햇빛의 주름 · Folds of Daylight

청회색 바탕 위에 황금빛 부채꼴 면을 펼쳤습니다. 높이가 번갈아 달라지는 방사선 사이를 평면 패널로 연결하고, 밝기와 바닥 그림자로 접힌 방향을 드러내는 연구입니다.

![청회색 바탕 위에 펼쳐진 황금빛 주름과 오른쪽으로 드리운 톱니 그림자](output/Folds-of-Daylight.png)

**조형 연구로 보존합니다. 완성 작품 채택은 보류합니다.** 밝고 어두운 면의 반복은 잘 읽히지만, 동일한 폭과 규칙적인 꼭짓점 때문에 조형물보다는 부채나 구조 도식의 인상이 강합니다. 질감을 덧붙여 완성도를 대신하기보다 이번 결과의 기하와 투영을 남겼습니다.

## 형태와 그림

안쪽 반지름 0.72, 바깥쪽 3.2, 펼침 각도 264도인 고리의 일부를 24개 패널로 나눴습니다. 낮은 방사선은 높이 0.04, 높은 방사선은 반지름에 비례해 높아집니다. 각 방사선이 같은 가상 꼭짓점을 지나므로 이웃 방사선 사이의 사각형은 평면입니다.

현재 결과는 **두께 없는 면의 직교 투영 벡터 그림**입니다. 면의 밝기는 법선과 평행광 방향으로 정한 단순 색 계산이고, 바닥 그림자는 같은 광선 방향으로 좌표를 평면에 내린 것입니다. 겹치는 그림자를 한 마스크로 합쳐 중첩부가 두 번 어두워지지 않게 했습니다. 면끼리 드리우는 자기 그림자, 반사광, 부드러운 그림자나 종이의 재질은 계산하지 않았습니다.

패널을 카메라 깊이 평균값 순서로 그렸습니다. 이 배치에서는 4픽셀 간격 122,500개 화면 표본 중 면에 해당하는 22,097개에서 삼각형 보간 깊이와 그리기 순서의 불일치를 발견하지 못했습니다. 이 표본 검사는 모든 기하에서 성립하는 은면 제거 알고리즘의 증명이 아닙니다.

## Blender 경로와 미실행 범위

처음에는 두께·가장자리 처리와 조명을 포함한 Blender 장면을 만들려 했습니다. 실행이 장면 저장 전에 종료 코드 137로 끝났고, 최소 배경 실행도 같았습니다. 원인은 확정하지 않았습니다. 따라서 `.blend`와 Blender 렌더는 생성하지 못했습니다.

그 제작안은 [build_blender.py](build_blender.py)에 보존하되 **실행 완료·검증된 제작 경로로 표시하지 않습니다.** 수정자 적용 후 닫힘·부피·지면 관통 검사도 하지 않았습니다. 지금 보이는 SVG·PNG는 별도 `build.py`가 생성한 결과이며 Blender 출력으로 소개하지 않습니다.

실제 종이의 접힘 과정·재료 물성·구조 안정성·제조 가능성은 검증하지 않았습니다. 종이접기 설명서나 제작 도면이 아닙니다.

## 재현과 검사

현재 벡터 제작에는 Python, NumPy, Inkscape가 필요합니다. 이미지 검사에는 Pillow를 씁니다. 별도 사본에서 제작하면 기존 출력을 덮어쓰지 않습니다.

```sh
python3 build.py
python3 verify_geometry.py
python3 verify_projection.py
python3 verify.py
```

기하 검사는 좌표식과 저장된 좌표를 대조하고 패널 평면성·면적·법선·연결성을 확인합니다. 좌표 차이는 0, 패널의 최대 평면 오차는 약 2.78×10⁻¹⁶이었고, 모든 면의 법선 z 성분은 양수였습니다. 표면은 하나로 연결되고 경계 루프가 하나이며, 최소 높이는 0.04입니다. 기본 검사 실행은 파일을 바꾸지 않습니다. 구체적인 수치와 미실행 범위는 [기하 검사 설명](GEOMETRY_QA.md)과 `geometry_qa.json`에 있습니다.

최종 PNG 전체를 직접 확인했습니다. 제작 소스만 옮긴 별도 사본에서 SVG·PNG·좌표 JSON이 바이트까지 동일하게 재생성됐습니다. `manifest.json`은 자신을 제외한 보존 파일의 크기·SHA-256을 기록합니다. 캐시·임시 출력은 보존하지 않습니다.
