# 기본 패널 기하 검증

`verify_geometry.py`는 Python 표준 라이브러리만 사용한다. `build.py`를 실행하거나 가져오지 않고, 허용한 수식과 반복문을 AST로 읽어 실제 `output/geometry.json`과 대조한다. 검사에는 렌더링 코드의 면 법선 계산 결과를 재사용하지 않는다.

프로젝트 폴더에서 실행한다.

```sh
python verify_geometry.py
python verify_geometry.py --report
```

첫 명령은 JSON을 화면에 출력하며 파일을 변경하지 않는다. 두 번째 명령만 `geometry_qa.json`을 기록한다. 실행한 검사가 모두 통과하면 종료 코드 0, 기하 검사 실패 시 1을 반환한다. 기본 실행 전후 프로젝트 파일의 목록·내용 해시·수정 시간을 비교하여 변경이 없음을 확인했다.

## 실행 결과

기본 표면 검사 13개가 통과했다. 수치 단위는 장면 단위이며, 실제 길이·면적 단위로 환산하지 않았다.

- 소스 수식과 내보낸 좌표 차이: **0**. 꼭짓점 50개, 사각 패널 24개.
- 최대 평면 이탈: **2.78 × 10⁻¹⁶**. 거리 허용 오차는 10⁻⁹.
- 모든 패널이 볼록하며, 패널당 면적 약 **1.60706658**, 합계 **38.56959800**. 별도의 면적식과 최대 차이는 1.56 × 10⁻¹⁵.
- 면과 꼭짓점은 각각 하나로 연결된다. 변 73개 중 내부 변 23개, 경계 변 50개이며 경계 루프는 1개다. 오일러 특성은 1, 공유 변의 방향 불일치는 0이다.
- 모든 패널 법선이 위를 향한다. 법선 z 성분 최솟값은 **0.57712877**.
- 기본 표면의 높이 범위는 **0.04–0.904**다. 평면성과 볼록성을 함께 검사했으므로 패널 내부도 지면 z = 0 아래로 내려가지 않는다.

면적 대조식은 `A = (R² − r²) × √(sin²(Δθ) + s²) / 2`다. 이 모델처럼 인접한 방사선의 기울기가 0과 s로 번갈아 바뀌는 경우에 적용했다.

별도 검사에서 보존된 `build_blender.py`의 기본 좌표·면·매개변수도 현재 소스와 일치했다. 꼭짓점 비평면 변형, 면 뒤집기, 패널 누락, 지면 아래 이동, 변 붕괴, 잘못된 꼭짓점 번호의 여섯 가지 의도적 오류가 각각 실패로 검출됨을 확인했다.

## 미실행 항목과 한계

Blender가 종료 코드 137로 중단되어 `.blend`와 modifier 적용 메시가 생성되지 않았다. **Solidify/Bevel 적용 후 메시의 닫힘, 양의 부피, 지면 관통 검사는 미실행**이며 보고서의 `unrun_checks`에 분리했다. 보고서의 `status: pass`는 실행한 기본 표면 검사에만 해당한다.

기본 표면은 경계가 있는 두께 없는 면이다. 닫힌 입체, 실물 종이의 물성·접힘 과정·구조 안정성·제조 가능성, 물리 시뮬레이션을 검증했다고 주장하지 않는다. 전역 자기 교차, SVG 가림 순서, 그림자의 광학적 정확성, 시각적 완성도도 이 검사의 범위 밖이다. 조형의 최종 채택 여부는 기하 검사 통과와 별개다.
