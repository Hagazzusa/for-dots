# 저울을 덮어 둔 밤

버스가 지나간 뒤에도, 시장길의 밤은 조금 더 이어진다.
누군가 빈 저울을 닦고 천을 접어 올려놓았다.
내일 다시 쓸 물건들은, 오늘의 자리에 남아 있다.

**직접 작성한 SVG 도형을 Inkscape로 렌더한 벡터 정물이다. 실물 사진·Blender 렌더·생성형 이미지·게임 화면이 아니다.**

## 같은 동네의 새로운 모퉁이

갤러리와 가상 동네 설정집을 확인했다. 시장길은 08번 노선의 다음 구간과 승객의 목적지, 《다음 정거장》의 가상 승차권에 등장하지만, 시장길의 장소 자체를 중심으로 한 주요 정지 작품은 없었다. 기존 정류장·꽃집·집·수리된 벤치·수레의 구도를 반복하지 않고 작은 과일 가게 앞의 저울 한 대를 골랐다.

과일 가게와 천을 접어 놓는 행동은 **이번 동반 그림의 새로운 상상**이다. 게임에 구현된 장소나 사건으로 확정하지 않으며 사용자의 개인사를 재현하지 않는다. 천은 잃어버린 물건이나 수수께끼가 아니라, 닦아 두고 다시 쓸 일상용품이다. 사람·새 비극·퀘스트·가격표는 넣지 않았다.

버스가 지나갔다는 시간은 짧은 동반 글의 설정이다. 그림에는 버스나 승객, 특정 운행의 증거가 없으며 이미지 자체가 정확한 시간을 전달한다고 주장하지 않는다. 막차 제한이나 서둘러야 하는 사연도 덧붙이지 않는다.

## 그림과 파일

차가운 셔터의 수평선과 밝은 천의 접힘을 대비했다. 천의 하단과 옷단에는 부드러운 곡선과 처짐을 주었지만, 여전히 종이 오리기처럼 단순화한 벡터 표현이다. 실제 직물·광학·저울 측정의 물리 시뮬레이션이 아니다. 눈금은 저울을 암시하는 그래픽이며 측정 범위나 교정 사양을 나타내지 않는다.

- `market_scale.svg`: 개별 도형을 편집할 수 있는 SVG 원본. 한국어 title·desc 포함.
- `market_scale_final.png`: 1800 × 1400 최종 이미지.
- `market_scale_draft.png`: 승인된 900 × 700 초안.
- `build.py`: SVG와 PNG를 다시 만드는 Python 표준 라이브러리 소스.
- `validation.json`: SVG 재개방·참조 검사, 반복 내보내기 픽셀 비교와 PNG 메타데이터 기록.
- `provenance.json`: 재료·세계관·표현 범위.
- `verify_bundle.py`: 동결 파일 해시와 SVG·PNG의 기본 검증.

설치된 Inkscape 1.4를 사용했다. 사진·비트맵 텍스처·외부 메시·글꼴·브랜드·다운로드한 자산은 없다. SVG는 외부 참조, 실행 스크립트, 내장 이미지 또는 화면에 렌더되는 문자를 포함하지 않는다.

```sh
python build.py           # 1800 × 1400 최종 PNG
python build.py --draft   # 900 × 700 초안 PNG
python verify_bundle.py  # 배포된 동결본 검사
```

빌드는 이 폴더의 SVG와 해당 PNG를 다시 만든다. 앱 설정·캐시는 `work/`에 둔다. 재생성 후에는 해시와 PNG 텍스트 메타데이터를 다시 검토해야 한다. 동결본 검사는 재생성하지 않은 배포 파일을 대상으로 한다.

독립적으로 두 번 내보낸 최종 이미지의 픽셀과 원래 PNG 바이트가 같음을 확인했다. 공개 PNG의 텍스트 청크를 제외할 때 IDAT와 디코딩 픽셀은 유지했다. 고해상도 최종 픽셀도 직접 확인했다. 기존 작품과 게임과는 별도의 그림이다.
