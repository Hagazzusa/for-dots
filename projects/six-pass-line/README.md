# 여섯 번의 한 줄

연필과 종이를 위한 한 사람의 소리 악보입니다. 6cm 간격의 두 점 사이를 번갈아 여섯 번 이동합니다. 세 번 왕복하는 동안 연필을 떼지 않습니다.

[한 쪽 악보 PDF](output/pdf/Six-Passes-One-Line.pdf) · [편집 원본](score.json)

## 구성

각 구절은 여덟 박입니다. 움직이는 시간은 6·4·2·2·4·6박, 끝점에 머무는 시간은 2·4·6·6·4·2박입니다. 한 박을 약 1초로 세면 전체 길이는 약 48초입니다.

처음과 마지막의 시간 배분은 같지만 연필은 이미 같은 자리를 여러 번 지나왔습니다. 종이 표면과 흑연이 달라질 수 있으므로 같은 소리가 되풀이된다고 정하지 않았습니다. 압력과 소리 크기를 맞추기보다, 편안한 힘으로 선을 되짚으며 그 차이를 듣는 악보입니다.

검은 막대는 움직이는 시간이고, 빈 원은 연필 끝을 종이에 댄 채 머무는 한 박입니다. 빈 원에서 문지르거나 힘을 더 주지 않습니다. 여섯째 구절의 마지막 머묾이 끝나면 가볍게 연필을 뗍니다. 남은 선을 지우지 않습니다.

## 상태와 검토 범위

**실연 전 악보입니다.** 시간 배분, 방향, 되돌아오는 끝점과 인쇄 배치를 검토했습니다. 실제 마찰음의 차이, 주변 소음 속에서의 들림, 손의 편안함은 실연·청취로 확인하지 않았습니다. 연필·종이·누르는 힘에 따른 소리 차이가 있으며, 녹음 결과물은 만들지 않았습니다.

PDF의 모든 내용을 렌더 이미지로 확인하고, 한글 글꼴·글자 경계·시간표·두 점의 60mm 간격을 검사했습니다. 별도 사본의 재생성 결과도 비교했습니다. A4 실제 크기 100% 인쇄에서 6cm이며, 다른 배율이나 화면으로 볼 때는 빈 종이에 6cm 간격의 두 점을 따로 표시합니다.

## 파일과 재현

- `score.json`: 제목·지시문·구절별 시간 배분을 담은 편집 원본.
- `verify_score.py`, `timing.json`: 시간 배분과 각 박 경계의 위치 검사.
- `build_pdf.py`, `layout.json`, `output/layout_manifest.json`: 악보 제작과 배치 설정·출력 구성 기록.
- `verify_pdf.py`, `qa_layout.json`: PDF 검사와 결과.
- `output/pdf/Six-Passes-One-Line.pdf`: 읽고 연주할 수 있는 한 쪽 악보.
- `manifest.json`: 보존 파일의 크기와 SHA-256.

기존 결과물을 덮어쓰지 않도록 별도 사본에서 실행합니다.

```sh
python3 verify_score.py
python3 build_pdf.py
python3 verify_pdf.py
```

두 검사 스크립트의 기본 실행은 파일을 바꾸지 않습니다. PDF 검사 보고서를 따로 저장하려면 `--report 파일명.json`을 지정합니다.

시간 검사는 Python 표준 라이브러리만 사용합니다. PDF 제작·검사 의존성은 제작 코드의 설명을 참고하세요. Noto Serif CJK KR 글꼴은 SIL Open Font License 1.1에 따라 PDF에 부분집합을 포함합니다.
