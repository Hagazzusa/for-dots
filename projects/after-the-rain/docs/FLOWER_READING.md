# 꽃집 쪽지와 인사 시간

꽃집 쪽지를 먼저 읽다가 주인의 짧은 인사 기회를 놓치지 않도록, 해당 쪽지가 열려 있고 주인으로부터 수평 거리 3.2m 안에 있을 때 **아직 인사하지 않은 창가 대기 단계의 남은 시간만 보존**한다.

- 포장지를 정리하는 동작은 끝까지 진행한 다음 창가에서 기다린다. 팔이나 포장지를 움직이던 자세로 멈추지 않는다.
- 쪽지를 닫거나 읽는 자리를 떠나면 남은 대기 시간이 다시 흐른다. 다시 열어도 12초를 새로 주지 않는다.
- 인사한 뒤의 답례·퇴장, 이미 끝난 방문에는 적용하지 않는다. 기존처럼 멀리 나갔다 돌아오면 다음 방문이 시작된다.
- 다른 쪽지, 숨겨진 독자 화면에는 적용하지 않는다. 버스, 저녁 시계, 고양이, 차의 남매 등 다른 장면은 계속 흐른다. 읽는 동안 버스를 놓칠 수도 있다.

## 책임과 검증

`Exploration`은 독자 화면의 실제 이야기 Resource를 확인해서 지역 동작에 조건을 전달한다. `FlowerLife`는 자신의 단계·거리·남은 시간만 관리한다. 전역 일시정지나 새 타이머는 추가하지 않는다.

`tests/flower_reading.gd`는 큰 시간 간격에서의 포장→대기 전이, 반복 열기/닫기, 거의 끝난 대기 시간, 인사 후 재기회 방지, 거리 이탈, 다른 이야기, 숨김, 리셋을 확인한다. 실제 main 인스턴스의 Session 갱신을 25초 진행하여 버스·시계·다른 배우가 계속 움직이는 양성 대조도 포함한다. 이 시간 주입 검사는 실제 UI 조작 관찰과 구별한다.

## 확인 결과

Godot 4.6.3에서 전체 47개 테스트 suite가 실패 없이 통과했다. 새 독서 suite는 41개 검사를 통과했다. 격리 PCK는 런타임 파일 186개로 구성되며, 일반 실행과 테스트 인자를 붙인 실행 모두 정상 입력을 유지하고 테스트 도구는 포함하지 않는다.

별도 이름의 네이티브 후보에서 방향키와 이동 키로 꽃집에 접근하여 쪽지를 열었다. 방문 대기 시간이 약 10.87초 지난 시점에 읽기를 시작했고, 게임 시계가 약 34.20초에서 84.23초까지 진행하는 동안 이 값이 보존됐다. 페이지를 넘긴 뒤 Q로 닫고 E로 실제 손인사와 답례 자막을 확인했다. 그 사이 버스는 대기에서 정차로 진행했다. 인사 후 주인은 정상 퇴장했고, 다시 쪽지를 열어도 돌아오지 않았으며 버스 표시는 다음 대기로 넘어갔다.

이 관찰은 텔레포트·시간 가속 없이 일반 main 장면에 제목과 읽기 전용 상태 로그만 추가한 임시 실행에서 했다. 로그 도구는 프로젝트와 PCK에 포함하지 않는다. 포장 동작의 매 프레임이나 다른 오디오 드라이버까지 검증한 결과는 아니다. 클라우드 오디오는 청취하지 않았다.
