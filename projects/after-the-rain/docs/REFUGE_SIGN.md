# 쉼터 외부 안내의 뒷면

쉼터 벤치에 앉으면 입구의 ‘늦은 밤에도 잠깐 쉬어 가세요’가 좌우 반전되어 시야 가운데 보였다. 실제 기본 시작 위치에서 꽃집을 거쳐 쉼터에 걸어 들어가 앉는 경로에서 확인했다.

`scenes/neighborhood_extension.tscn`의 기존 `RefugeSign`에 `double_sided = false`만 저장했다. 문구·글꼴·크기·위치·방향·깊이 검사와 읽기 타깃은 그대로다. 기존 Label3D의 Inspector 속성으로 해결하며 별도 스크립트·타이머·@tool·재질·광원은 추가하지 않는다. 다른 간판의 뒷면까지 일괄 변경하지 않는다.

[Godot 4.6 Label3D 공식 문서](https://docs.godotengine.org/en/4.6/classes/class_label3d.html#class-label3d-property-double-sided)는 이 속성이 false일 때 뒷면에서 글자가 보이지 않는다고 설명한다. 확인일: 2026-11-03. 엔진은 Godot 4.6.3 Compatibility이다.

## 검증 범위

- `tests/refuge_sign.gd`: 저장된 단면 설정, 기존 문구/크기/위치/방향, 깊이 검사, 다른 간판 보존, 두 인스턴스 분리, reset과 새 인스턴스의 설정 유지. 속성 검사는 실제 화면 가독성 검사를 대신하지 않는다.
- 전체 자동 회귀 54개 suite에서 실패 0개. 개별 간판 검사 8개도 통과했다. 첫 실행은 새 테스트의 `pixel_size == 0.005` 정확 비교가 float 정밀도 때문에 실패했고, 제품 값을 바꾸지 않고 `is_equal_approx`로 고친 뒤 전체를 다시 통과했다.
- PCK 193파일 생성·격리 경로 감사 및 PCK 대상 간판 검사 8개 통과. 기존 도시 리소스 UID의 text-path fallback 경고는 남아 있으며 무경고 실행을 주장하지 않는다.
- 실제 1180×812 임시 앱에서 외부 안내 앞면을 읽을 수 있음을 확인했다. 입구 앞 위치를 지정한 테스트 fixture에서 시작하여 실제 W/S·방향키로 들어가 E로 앉았고, 앉은 시야에서는 반전된 글자가 사라졌다. 이번 후보 검사는 기본 시작부터 전체 여정을 다시 플레이한 것은 아니다.
- 네이티브 실행은 소프트웨어 렌더링과 Dummy 오디오였으며 VSync 미지원 경고가 있었다. 소리 감상·편집기 수동 조작·모든 각도 검사는 하지 않았다.

이 변경은 외부 안내의 반전된 뒷면만 감춘다. 시각 장애 접근성, 모든 화면 크기·시야각의 가독성이나 성능 개선을 검증했다는 뜻은 아니다.
