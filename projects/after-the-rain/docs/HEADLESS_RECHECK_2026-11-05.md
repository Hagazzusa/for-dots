## 검사 종료 정리 보강

`tests/refuge_seating.gd`만 변경했다. 기존에는 오디오를 멈추고 세션을 해제한 뒤 고정 0.2초를 기다렸다. 이제 기존 세션 종료 API `_prepare_app_shutdown()`으로 모든 오디오 소유자의 종료를 요청하고, 세션을 해제한 뒤 playback의 약한 참조가 실제 사라지는지 최대 2초 동안 확인한다. 해제가 되지 않으면 테스트 단언 실패로 처리한다. 기능 단언이나 누수 검사 기준은 완화하지 않았다.

게임 동작 코드는 변경하지 않았다. 이 보강은 관찰된 종료 타이밍에 대한 더 정확한 검사 방식이며, 수정 전 간헐적 누수의 정확한 내부 원인을 확정했다는 의미는 아니다.
