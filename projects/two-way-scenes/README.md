# 두 방향의 장면

**보류 연구입니다. 완성된 희곡이나 시로 선정하지 않았습니다.**

같은 대사를 위에서 아래로, 아래에서 위로 읽을 때 서로 다른 선택이 생기는지 시험했습니다. 화자와 문장 내부는 그대로 두고 행 순서만 뒤집습니다. 리본을 자르려는 장면과 사진을 찍으려는 장면을 썼으며, 리본 장면의 두 행을 완료 행동으로 바꾼 대조도 남겼습니다.

- [세 시험의 두 방향 읽기](output/readings.txt)
- [편집 원본](scenes.json)
- [구체적인 연결 문제와 보류 판단](REVIEW.md)

양 끝에 반대 의사를 놓으면 읽기 방향에 따라 결론은 달라집니다. 그러나 이번 초안에서는 도구를 누가 들고 있는지, 실제로 어떤 행동을 했는지 자주 빠져 있습니다. 자연스러운 장면이 만들어졌다고 보기 어려워 꾸민 읽기용 PDF나 공연본으로 확장하지 않았습니다.

## 재생성과 검사

Python 3 표준 라이브러리만 사용합니다. 결과를 다시 만들 때는 이 폴더를 별도 위치에 복사해 실행합니다.

```sh
python3 build.py
python3 verify.py
```

`build.py`는 `scenes.json`에서 `output/readings.txt`를 만듭니다. 출력의 숫자는 읽는 순서가 아니라 원래 행 번호입니다. `verify.py`는 파일을 바꾸지 않고 두 방향의 대사·화자·행 번호 보존, 12·15·12행의 길이, 대조에서 바뀐 두 행을 확인합니다. 매니페스트가 있으면 기록한 파일 해시도 확인합니다. `qa.json`은 순서·원문 보존 검사 기록이며 문학적 품질 점수가 아닙니다.

공개 파일만 복사한 별도 사본에서 읽기 자료를 다시 만들어 바이트 일치를 확인했습니다. 기본 검사 전후 파일 목록과 바이트도 같았습니다. 대사와 두 방향의 연결은 따로 읽어 검토했으나, 배우의 낭독이나 독자 실험은 하지 않았습니다. 역순 문학 일반이 불가능하다는 주장이 아니라 이 초안들의 한계를 기록한 연구입니다.
