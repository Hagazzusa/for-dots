# 모서리를 맡은 사람들 · The Held Corners

큰 젖은 시트를 빨랫줄에 거는 두 사람. 얼굴 대신 샌들과 맨발, 이미 집힌 왼쪽 끝과 아직 손으로 든 오른쪽 끝이 일을 나누어 보여 준다.

## 결과와 판단

완성 작품으로 선정했다. 손과 발의 일부 회화적 과장은 남지만, 장면을 혼란스럽게 만들거나 보류할 정도의 결함으로 판단하지 않았다.

[원본 이미지](output/The-Held-Corners.png)는 1536×1024 RGB PNG다. 파스텔·과슈풍의 생성 이미지이며 실물 회화나 사진은 아니다. 따뜻한 벽과 넓은 천, 작은 파란 대야가 만든 간결한 색 덩어리를 중심에 두었다. 얼굴이 없어도 왼쪽의 안정된 발과 오른쪽의 들린 뒤꿈치로 동작의 차이가 읽힌다.

기존 《낮은 모서리》와 천을 사이에 둔 두 사람이란 소재는 닿아 있지만, 이 그림은 물을 빼는 순간이 아니라 한쪽을 고정한 뒤 다른 쪽을 올리는 순간이다. 기존 작품의 인물이나 연속 장면으로 설정하지 않았다.

## 제작과 보존

이미지 생성 도구로 외부 참고 이미지 없이 한 번 생성했다. 생성 원본을 바이트 변경 없이 복사했으며 리터치·크롭·업스케일은 하지 않았다. 실제 전달한 영문 지시문은 [prompt.txt](prompt.txt)에 보존했다. 프롬프트는 같은 픽셀을 다시 만드는 실행 코드가 아니다. 편집 레이어·직물 시뮬레이션·3D 장면은 없다.

## 확인 범위

전체 화면에서 천의 실루엣, 네 다리, 가려진 얼굴, 빨랫줄과 집게, 손·천의 접점, 대야의 여백을 살폈다. 오른쪽 발끝은 표현이 과장되어 있고 위쪽 손과 가려진 몸통의 연결은 천 때문에 직접 확인할 수 없다. 이를 정확한 해부학이나 실제 동작의 증명으로 취급하지 않는다. 천의 젖은 반점은 작은 물방울 자국처럼 강조되었다. 짧고 자연스러운 동작을 담은 회화로 평가하며 실제 천의 무게·투과·그림자 모델을 검증하지 않았다.

`python3 verify.py`는 PNG 전체 디코드·크기·색상 모드와 매니페스트의 바이트 수·SHA-256을 읽기 전용으로 검사한다. 이 검사는 미술적 완성도를 자동 판정하지 않는다. 실물 인쇄와 다른 화면의 색 재현은 확인하지 않았다.

보존 범위는 이 문서, 생성 지시문, 원본 PNG, 검토 기록, 읽기 전용 검사 코드, 매니페스트의 여섯 파일이다. 이전 프로젝트는 수정하지 않았다.
