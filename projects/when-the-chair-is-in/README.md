# 의자를 넣고 나면

26초 소리 소품. 의자를 식탁 밑으로 밀어 넣는다. 한 번 걸렸다가 다리가 자리를 찾는다. 그 뒤에는 조금 전까지 들리지 않던 바닥의 낮은 울림이 남는다.

[MP3 듣기](When-the-Chair-Is-In.mp3) · [편집 가능한 제작 원본](build.py)

- 2초에서 5초 사이에 마찰음이 왼쪽에서 가운데로 건너간다.
- 7초쯤 의자를 조금 더 민다. 11초쯤 아주 작은 소리 하나가 늦게 난다.
- 마지막에는 방의 기척도 서서히 걷힌다.

## 제작

마찰음은 대역을 좁힌 잡음을 촘촘히 끊어 만들고, 나무가 부딪히는 소리는 감쇠 속도가 다른 정현파를 겹쳤다. 시작 위치, 길이, 세기는 `build.py`의 `FRICTION`과 `CONTACTS`에서 바꿀 수 있다.

Python 3, NumPy, FFmpeg(`libmp3lame` 포함)가 필요하다.

```sh
python3 build.py --out /tmp/When-the-Chair-Is-In.mp3
```

## 확인 범위

44.1kHz 스테레오 MP3를 처음부터 끝까지 디코딩해 26초 분량과 클리핑 없음, 마지막 반 초의 무음, 같은 환경에서의 바이트 일치 재생성을 확인했다. 소리를 실제로 들어 음색이나 청취 경험을 검토하지는 못했다.
