# 평면 물 경계 · 2×2 기준 실험

완성 작품이나 실제 얕은 웅덩이가 아닌 **이상화된 단일 경계의 조명·바닥 대비 연구**다. 낮은 시점이나 새 물 재질을 추가하지 않았다.

## 먼저 볼 그림

- `matrix.png`: 2×2 실제 렌더. 위/아래는 바닥 배율 1/2, 왼쪽/오른쪽은 환경 띠 추가 강도 0.2/1.0.
- `seed_comparison.png`: 두 극단 LL·HH만 시드 137과 271로 비교.
- `roi_layout.png`: 첫 미리보기에서 고정한 네 영역.
- `renders/`: 여섯 조건의 개별 PNG·32비트 선형 RGB EXR·EXR에서 읽은 선형 배열.

그림을 나란히 배치하고 이름만 붙였다. 반사를 지우거나 덧그리지 않았다. 첫 LL 미리보기에서 띠와 격자가 구별되었지만 표시가 어두워, **다른 조건을 보기 전에 모든 PNG의 노출을 +2로 고정**했다. 초기 노출 0 이미지도 남겼다. 선형 EXR 값은 이 표시 선택으로 바꾸지 않았다.

## 장면과 통제

- Blender 4.3.2, Cycles CPU 두 스레드. 400×300, 32샘플, 적응형 샘플링·디노이징 OFF.
- 기본 시드 137, 극단 LL·HH의 추가 반복만 271. 최초 미리보기를 LL 조건으로 사용해 **렌더는 총 여섯 번**이다.
- 카메라 (0, −2.135, 1.013) m, 원점 응시, 원근 50 mm·센서 36 mm. 중심 시선 고도 약 25.38°.
- 수면 z=0, 법선 +Z인 100 m 평면. 흰 Principled, Transmission 1, IOR 1.333, Roughness 0, Metallic·Coat 0, 볼륨·흡수·bump 없음.
- 불투명 확산 바닥 z=−0.01 m, 0.2 m 격자. 선형 RGB 회색 0.1/0.2에 공통 배율 1 또는 2만 적용했다.
- World의 균일 배경은 0.05. 고도 22.38–28.38°에 해당하는 띠 마스크에 추가 방사 강도 0.2 또는 1.0만 곱했다. 띠 안의 총 입력은 0.25 또는 1.05다. 마스크는 직접 만든 1024×512 float 환경맵이며 모든 조건에서 동일하다. 픽셀화 때문에 실제 경계는 약 22.5–28.48°다. 별도 라이트·카메라 가시성 편법은 없다.
- 바운스·카메라·기하·재질의 나머지 값과 AgX Medium High Contrast, 표시 노출 +2, gamma 1은 고정했다.

물체가 닫힌 얕은 부피인 것이 아니다. 단일 면 아래를 물 반공간으로 취급하고 10 mm 아래 불투명 바닥을 둔 이상화다. 두 번째 출구 면이나 물의 외곽·메니스커스·실제 용량을 모델링하지 않았다. 이 모델이 물처럼 읽힌다는 증명도 아니다.

## 미리보기 검증과 고정 영역

다른 세 조건을 렌더하기 전에 첫 LL 화면만 보고 영역을 정하고 JSON 해시를 고정했다. **LL 미리보기를 관찰한 뒤 선정했으므로 완전한 사전등록이 아니다.** 네 영역은 겹치지 않는다. 좌표는 왼쪽 위 원점, [x0,y0,x1,y1)이다.

| 영역 | 픽셀 경계 | 기하 확인 |
|---|---|---|
| 띠 안 | [160,140,185,160] | 반사 고도 24.34–26.35°, 띠 안 |
| 띠 밖 | [165,202,185,222] | 반사 고도 30.72–32.70°, 띠 밖 |
| 밝은 격자 | [143,238,173,258] | Snell 경로로 예측한 한 격자 위상만 포함 |
| 어두운 격자 | [212,238,242,258] | 반대 격자 위상만 포함 |

실제 화면에서 별도 환경 띠와 그 아래 바닥 격자가 구별된다. +Z 법선과 IOR를 사용해 예측한 굴절 바닥 위치에서 밝고 어두운 격자가 맞게 읽혔다. 이는 경계 통과와 배치가 예상과 일치하는 제한된 확인이지, 단일 경계 모델의 모든 내부 경로 또는 실제 얕은 물을 검증한 것은 아니다.

중심의 이상적 비편광 Fresnel 계산은 약 8.4475%다. 화면은 원근이며 위치마다 입사각이 다르다. 이 값은 픽셀의 밝기 비율·반사 기여율이나 선명도가 아니다.

## 선형 EXR에서 읽은 결과

모든 EXR은 동일 렌더 결과에서 저장한 RGB 각 채널 32비트 float다. 헤더의 채널 형식과 유한값을 검사하고 Blender의 Linear Rec.709로 읽었다. 아래 값은 Y=0.2126R+0.7152G+0.0722B로 계산한 고정 영역의 공간 평균이다. 물리 단위로 보정한 방사량이 아니며, 이 선형 RGB 또는 Y 값 자체는 반사율이 아니다.

| 조건 | 띠 안 | 띠 밖 | 밝은 격자 | 어두운 격자 |
|---|---:|---:|---:|---:|
| LL: 띠 0.2, 바닥 ×1 | 0.026952 | 0.006443 | 0.009982 | 0.005964 |
| HL: 띠 1.0, 바닥 ×1 | 0.100512 | 0.010382 | 0.018028 | 0.010021 |
| LH: 띠 0.2, 바닥 ×2 | 0.033394 | 0.010478 | 0.018481 | 0.009984 |
| HH: 띠 1.0, 바닥 ×2 | 0.113911 | 0.018430 | 0.035136 | 0.018299 |

- 바닥 ×1에서 띠 강도를 높이면 선택한 띠 안팎 두 영역의 출력 평균 차이가 **0.020509→0.090130**으로 커졌다.
- 띠 0.2에서 바닥을 밝히면 밝은/어두운 격자 차이가 **0.004018→0.008497**로 커졌다.
- 띠 강도를 높여도 격자 자체가 밝아진다. World가 바닥 조명도 바꾸므로 결과는 순수 반사와 순수 투과의 분해가 아니다.
- 띠 안 영역은 바닥 격자 두 위상을 일부 포함하고 띠 밖 영역은 한 위상이다. 또 두 영역은 화면 위치와 입사각도 다르므로, 두 영역 차이는 순수 반사 대비가 아니다. 이를 Fresnel 반사율로 읽으면 안 된다. 고정한 위치에서 조건 변화가 어떻게 나타나는지를 비교한 것이다.

두 극단의 다른 시드 반복에서 선택한 띠 안팎 두 영역의 출력 차이 변화는 LL 약 **0.0000206**, HH 약 **0.0001555**였다. 격자 대비 차이는 각각 약 **0.0001259**, **−0.0002546**이다. 이 관찰된 반복 차이는 위의 큰 조건 효과보다 작았으며 효과 방향도 유지되었다. 그러나 두 시드만으로 신뢰구간이나 통계적 유의성을 주장하지 않는다. 영역의 공간 표준편차는 Monte Carlo 표준오차가 아니다.

최종 표시 PNG에서 254 이상 채널을 가진 픽셀은 없었다. 띠를 강하게 할 때 노이즈가 늘어나는 모습도 보인다. 실제 관객에게 물 또는 유리로 읽히는지 평가하지 않았고, 이전 접시·웅덩이 실패의 단일 원인을 이 실험으로 확정하지 않는다.

## 계산 및 재현 경로

1. `run.py`: 조건별 독립 장면 생성 → 같은 렌더 결과의 PNG와 선형 EXR 저장 → EXR readback을 `*_linear.npy`에 저장.
2. `check_preview.py`: 카메라 광선·Snell 경로·반사 고도를 계산하고 고정 영역을 기록. 첫 LL 이후, 나머지 조건 이전에 실행했다.
3. `check_exports.py`, `use_exr_display.py`: 모든 PNG를 같은 EXR→AgX 표시 경로로 통일. 직접 저장한 PNG는 원래 연구 폴더의 `work/`에 보존했고 공개 묶음에서는 제외했다. 원래 직접 PNG와 EXR 재표시는 채널당 최대 2/255 차이가 있었으며, 선형 계산에는 PNG를 쓰지 않는다.
4. `analyze.py`: EXR 헤더·고정 설정·영역 해시 검사 → 선형 밝기와 시드 차이 계산 → 비교 그림 구성.
5. `records/`: 각 조건의 기록된 주요 설정, 고정 영역, 효과·반복 수치와 출력 일치 기록.

예: `blender -b --factory-startup -t 2 --python-exit-code 1 --python run.py -- HL`

이 명령은 해당 연구 조건의 파일을 다시 만든다. 원본 작품을 읽거나 덮어쓰지 않는다. 공개 묶음은 원본과 분리한 사본이다. 그림·EXR·native의 작업 경로 메타데이터만 정리했으며 역사적 원본과 공개 사본 해시는 `provenance.json`에서 구분한다.

## 공개 사본·재현 순서와 덮어쓰기

원본은 직접 작성한 절차형 장면과 1024×512 생성 환경맵이다. 다운로드한 이미지·메시·외부 연구 데이터는 없으며 새로운 공개 라이선스를 부여하지 않는다. `LL.blend` 한 개만 편집 가능한 기준으로 제공한다. 다른 조건의 native는 동일 소스로 재생성하므로 배포하지 않는다. 로그·작업 캐시·직접 PNG의 중간 사본도 제외한다.

Blender 4.3.2와 Python NumPy·Pillow를 사용한다. 먼저 배포 폴더 전체를 새 작업 폴더로 복사한다. 보존된 측정값만 다시 계산하려면 `python3 analyze.py`만 실행하면 된다. 이 명령도 `records/analysis.json`, `matrix.png`, `seed_comparison.png`, `roi_layout.png`를 덮어쓴다.

전체 재렌더는 아래 순서다. 이미 제공된 ROI 정의를 유지하며 LL 관찰 후 선정했던 역사적 순서를 새 사전등록처럼 재현한다고 주장하지 않는다. 각 `run.py`는 해당 `.blend`, 조건 JSON, PNG·EXR·NPY를 덮어쓴다. `check_exports.py`는 `work/`를 만들고 EXR 재표시 PNG와 색공간 JSON을 쓴다. `use_exr_display.py`는 여섯 배포 PNG와 표시 파이프라인 JSON을 다시 쓴다. 원래 연구 자료를 보존할 때 이 명령을 원본 폴더에서 실행하지 않는다.

```sh
for case in LL HL LH HH LL_repeat HH_repeat; do
  blender --background --factory-startup --disable-autoexec --threads 2 --python-exit-code 1 --python run.py -- "$case"
done
blender --background --disable-autoexec --threads 2 --python-exit-code 1 --python check_exports.py
python3 use_exr_display.py
python3 analyze.py
```

`set_display.py`는 최초 노출0의 LL을 보고 +2로 고른 **과거 선택 기록용 소스**다. 현재 `run.py`는 이미 +2로 설정되어 있으므로 이 스크립트를 다시 실행하지 않는다. 재실행하면 초기 노출0 증거 PNG를 현재 LL로 덮어쓴다. `check_preview.py`도 ROI JSON을 다시 쓰는 계산 소스다. 기존 ROI를 보존하는 위 재현 절차에는 넣지 않았다.

PNG 텍스트 청크 제거 전후의 IDAT·픽셀은 같고, EXR 6개는 같은 길이의 File 문자열만 바꿔 다른 헤더·오프셋·압축 픽셀 payload를 그대로 유지했다. native 출력·브라우저 경로는 상대화했으며 기하·재질·카메라·월드·렌더 설정과 생성 환경맵 픽셀을 원본과 비교했다. 실제 EXR 디코딩 RGB는 제공된 NPY와 비트 단위로 일치한다. 선형 출력이 Fresnel 반사율을 뜻하지 않는다는 한계는 이 정리 후에도 동일하다.
