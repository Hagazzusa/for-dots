# 확인 기록

검사일: 2026-11-03. 대상은 이 폴더의 정적 그림책입니다.

## 확인한 것

- 세 원작의 README와 실제 최종 렌더 픽셀을 읽고 확인한 뒤 본문·대체 텍스트를 작성했습니다. 찻잔의 차 유무, 빈 현관, 도자기 고양이를 구분했습니다.
- Node 24의 `test_story.cjs` 통과: 한 번에 한 장면, 첫 장·마지막 장 화살표 경계, 버튼 넘김, 처음으로 돌아가기, 30회 연속 클릭, 보조키·키 반복 무시, 입력 요소와 펼침 항목 보호, 비활성 버튼의 포커스 회복.
- 정적 검사: 한국어 문서 언어, 세 이미지의 대체 텍스트, 자바스크립트 없이 세 장면이 보이는 HTML, 외부 URL·네트워크 API·브라우저 저장 기능 없음.
- 관리형 로컬 HTTP 미리보기를 실제 Chromium UI로 열어 세 장면의 그림·글·버튼을 확인했습니다. 다음 클릭, 오른쪽 화살표, 처음으로, 첫 장의 왼쪽 화살표를 실제 조작했습니다.
- 같은 브라우저의 가로 390px iframe에서 세 장면의 세로 배치와 넘김을 확인했습니다. 세로 스크롤바를 뺀 콘텐츠 너비와 scrollWidth는 모두 375px로, 가로 넘침이 없었습니다. 작은 화면에서 넘긴 뒤 그림의 시작으로 돌아오는 것도 확인했습니다. 이 검사는 실제 휴대폰 기기 검사는 아닙니다.
- 패키지 생성 도구로 새 출력 폴더를 만들고, 세 PNG를 원본과 SHA-256 비교했습니다. 원본 이미지의 바이트와 포함 메타데이터는 수정하지 않았습니다.
- 기본 글꼴은 운영체제의 한국어 명조·고딕 계열입니다. 외부 글꼴을 내려받지 않습니다.

## 한계

- 브라우저 도구가 `file:` 프로토콜을 허용하지 않아 파일 직접 열기의 실제 브라우저 검사는 하지 못했습니다. 우회하지 않았습니다. 오프라인 구성은 상대 파일 참조·빌드 없는 일반 스크립트·네트워크 호출 부재와 복사된 파일 검사로 확인했고, 실제 조작 검사는 같은 파일을 로컬 HTTP로 제공하여 진행했습니다.
- 실제 모바일 기기, 다른 브라우저, 스크린 리더 음성 출력, 인쇄 결과는 검사하지 않았습니다. 동작 줄이기와 인쇄 분기는 CSS 소스 검토 범위입니다.
- 자동 상태 검사는 작은 DOM 대역을 사용합니다. 실제 브라우저 검사나 종합 접근성 인증을 대체하지 않습니다.
- 이 폴더는 기존 게임과 Blender 장면을 바꾸지 않습니다. 새로운 외부 사이트를 배포하지 않았습니다.
