# 한 줄의 바깥

[그림책 PDF 읽기](output/pdf/Outside-One-Line.pdf)

다섯 장의 벡터 그림책입니다. 한 선을 바꾸는 대신 그 주변에 집, 길, 눈금을 놓았습니다. 마지막에는 주변을 지워 처음의 선으로 돌아갑니다. 같은 것을 다시 볼 때 앞서 본 것이 얼마나 남는지 궁금해서 만들었습니다.

처음에는 접힌 종이를 포함한 더 많은 예시와 매 장의 설명문이 있었습니다. 여러 변신을 보여주는 도해가 되지 않도록 물체, 이동, 측정 세 가지만 남기고 중간 설명문도 지웠습니다. 독자가 보아야 할 결론은 적지 않았습니다.

## 결과와 원본

- `output/pdf/Outside-One-Line.pdf`: 최종 다섯 장. 480 × 600 pt. 그림은 벡터이며 글꼴은 부분 포함했습니다.
- `build.py`: 모든 그림과 조판을 만드는 코드. 적갈색 선을 한 번 정의해 같은 그리기 함수로 반복합니다.
- `design.json`: 좌표, 굵기, 색, 문구와 장별 구성.
- `description.txt`: 각 장의 그림을 설명한 별도 일반 텍스트.
- `verify.py`, `qa.json`: 최종 파일 확인 코드와 결과.

그래픽은 직접 그렸으며 외부 그림을 사용하지 않았습니다. 한글은 SIL Open Font License 1.1의 Noto Serif CJK KR을 부분 변환·포함했습니다. 원본 시스템 글꼴은 수정하지 않았습니다.

## 다시 만들기

Python의 reportlab, fontTools, pypdf, Pillow와 Poppler가 필요합니다. 기본 글꼴 위치는 코드에 명시되어 있습니다.

```sh
mkdir -p tmp/pdfs output/pdf
python3 build.py
pdftoppm -scale-to 850 -png output/pdf/Outside-One-Line.pdf tmp/pdfs/final
python3 verify.py
```

## 확인과 한계

다섯 장 모두 실제 최종 PDF를 이미지로 렌더해 확인했습니다. PDF 명령에서 같은 선의 좌표·색·굵기·끝 모양·모서리 모양을 다섯 번 확인했습니다. 첫 장과 마지막 장의 위쪽 70%는 렌더 이미지에서도 완전히 같습니다. 바뀌는 문구와 쪽 번호는 그 비교 영역 밖에 있습니다.

한글 추출과 글꼴 포함을 확인했습니다. 다만 PDF/UA 태그가 있는 접근성 문서는 아니므로 별도 그림 설명을 남겼습니다. 첫 장과 마지막 장의 감상이 달라지는지는 독자마다 다를 수 있습니다. 이 작업은 지각 실험의 결과를 입증하지 않습니다. 노선도와 그래프도 모두 허구이며 실제 경로 안내나 측정 기록이 아닙니다.
