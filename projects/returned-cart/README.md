# 돌아온 수레

벤치를 옮긴 뒤, 수레만 처마 아래로 돌아왔다.
풀어 놓은 천끈은 그대로이고, 문 앞은 비워 두었다.

**직접 만든 Blender 형상과 조명으로 렌더한 양식화된 정물이다. 실물 사진이나 게임 화면이 아니다.**

## 같은 동네의 다른 자리

기존 가상 동네 설정에서 목수는 집에서 쓰던 벤치를 작업실에서 수리해 유리 쉼터로 가져왔다. 《수선이 남긴 자리》는 그 수선과 벤치·대패·연필·담요를 이미 보여준다. 이 작품은 그 정물을 반복하지 않고, 작업실 바깥의 닫힌 문과 빈 적재면으로 시점을 옮긴다. 풀린 끈만으로 누군가 일을 마쳤다는 흔적을 남긴다. 사람, 읽어야 하는 쪽지, 새 사건이나 퀘스트는 없다.

수레로 벤치를 옮겼다는 세부는 기존 설정집에서 확인된 사실이 아니다. 같은 동네에 연결한 **새 동반 장면의 상상**이며, 게임에 구현되거나 기존 이야기를 확정하는 작업은 아니다. 원래 작품과 게임은 변경하지 않았다.

## 만든 것

수레, 바퀴, 닫힌 문, 판석과 끈을 기본 형상·곡선·직접 만든 메시로 구성했다. 나뭇결은 절차적 재질이며, 외부 사진·메시·텍스처·HDRI·글꼴을 사용하지 않았다. 끈은 열린 비대칭의 **수작업 리본 메시**다. 한쪽 끝은 길게 풀리고 다른 끝은 옆으로 돌아앉는다. 천 물리 시뮬레이션이 아니다.

채택한 초안과 같은 소품·구도·재질·조명으로 최종 이미지를 만들었다. Blender 4.3.2, Cycles CPU 두 스레드, 1200 × 933, 128샘플이며 디노이징은 사용하지 않았다. 밤의 분위기를 따뜻한 처마 빛과 차가운 보조광으로 표현했지만 비·물기·바퀴 변형을 시뮬레이션하지 않았다.

## 파일과 재현

- `Returned_Cart.blend`: 개별 물체와 재질을 편집할 수 있는 원본 장면.
- `build.py`: 외부 에셋 없이 장면과 이미지를 다시 만드는 코드.
- `renders/returned_cart_final.png`: 최종 실제 렌더.
- `renders/draft.png`: 열린 끈을 채택한 저비용 실제 초안.
- `audit.py`, `native_validation.json`: 저장본을 다시 열어 확인한 제한된 형상·참조 경로 검사.
- `provenance.json`, `visual_validation.json`, `metadata_validation.json`: 출처, 실제 픽셀 검토 및 공개 PNG의 메타데이터 정리 기록.
- `ARTIFACT_MANIFEST.json`, `PUBLIC_ALLOWLIST.txt`: 공개 사본에 포함할 파일과 해시.

```sh
blender --background --factory-startup --threads 2 --python build.py -- --draft
blender --background --factory-startup --threads 2 --python build.py
blender --background --factory-startup --threads 2 --python audit.py
```

재실행은 이 프로젝트의 해당 렌더와 Blender 파일을 새로 만든다. 새로 렌더한 PNG에는 Blender 텍스트 메타데이터가 다시 생길 수 있으므로 공개 전에 점검해야 한다. 저장된 최종 장면의 렌더 경로는 상대 경로다.

## 검증과 한계

첫 배치에서 뒤바퀴가 문턱과 겹쳤던 문제는 수레 자체를 문에서 220 mm 옮겨 수정했다. 닫힌 고리처럼 보였던 끈도 단일 열린 리본으로 바꿨다. 단순히 카메라로 문제를 숨기지 않았다.

기하 검사는 유한한 좌표·퇴화 면·참조 파일·일부 바퀴 아래 표면을 확인하는 범위다. 줄눈을 포함한 모든 접촉과 작은 조립 겹침을 증명하지 않는다. 운반 수레의 기계 설계, 하중, 안정성이나 실제 작업실 동선·안전을 검증한 결과가 아니며 제작 안내로 사용할 수 없다. 적재면의 빈 공간과 풀린 끈을 읽는 디지털 정물로 보아야 한다.

PNG의 경로·렌더 통계 텍스트 청크는 공개 사본에서 제외하되 이미지의 IDAT와 디코딩 픽셀은 보존한다. 생성 이미지 모델의 결과나 제3자 자산은 포함하지 않는다.
