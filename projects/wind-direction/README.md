# 바람의 방향

[짧은 이야기 읽기](story.md)

비 오는 날 정차한 차 안에서 두 사람이 말없이 머무는 독립 동반 소설입니다. 관계와 침묵의 뜻은 확정하지 않습니다. 실제 인물이나 개인사를 바탕으로 하지 않은 원문 창작입니다.

[게임의 세계관](../after-the-rain/narrative/WORLD_BIBLE.md)에는 이사 뒤 작별을 미루는 성인 남매가 있습니다. 이 글은 그 설정을 대체하거나 두 인물의 새로운 사건을 확정하지 않습니다. [옆자리 / Beside You](../beside-you/README.md)의 비·히터·말없는 동행과 분위기를 나누지만, 오디오의 시간별 장면을 옮긴 대본도 아닙니다.

송풍구를 조절하는 손, 젖은 소매, 돌아오는 고개와 히터를 낮추는 행동은 이 글에서 새로 상상했습니다. 게임에 구현된 동작이나 녹음된 소리를 보고한 것이 아닙니다. 배려 또는 조심스러움으로 읽힐 여지를 남기되 어느 해석도 정답으로 정하지 않습니다.
