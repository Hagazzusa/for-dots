# 귀에 든 물 · Water in One Ear

귀를 닦고 한쪽으로 몸을 기울입니다. 발가락이 시야 한쪽으로 모이고, 멀게 들리던 소리 뒤로 사물함의 철판 소리가 바로 곁에서 납니다.

**14행·4연의 독립 자유시로 채택했습니다.** 작은 몸의 동작과 소리의 거리 변화로 장면을 만들었습니다. 감정을 설명하는 결말이나 별도 그림을 붙이지 않고, 마지막 소리가 남도록 구성했습니다. 실제 경험담이나 사용자의 개인 기록을 옮긴 시가 아닙니다.

## 원고와 조판

첫 연에서는 멀게 들리는 드라이어, 마지막 연에서는 바로 곁의 철판 소리를 놓았습니다. 둘째 연은 머리를 기울인 뒤 달라진 시야, 셋째 연은 귓불 아래에 닿는 온도를 다룹니다. 발가락의 위치를 보는 대목은 의식적으로 관찰한 느낌이 있지만, 기울어진 몸을 설명 없이 보여 주는 장면으로 남겼습니다.

흰 바탕과 검은 글자만 사용했습니다. 제목 25pt, 본문 14pt, 행 간격 24pt이며 연 사이에 15pt를 더했습니다. 판면은 480×680pt입니다. 원문의 행과 연을 그대로 유지하고, 한 행을 자동으로 감거나 둘로 나누지 않습니다. 자유시이므로 정형 음수율이나 압운 충족을 주장하지 않습니다.

## 재현과 보존

Python, ReportLab, fontTools와 Noto Serif CJK Regular TTC가 필요합니다. 검사에는 pdfplumber·pypdf를 씁니다. [글꼴 배포 고지·라이선스](FONT_LICENSE.txt)를 보존하고, PDF에는 사용 문자만 변환해 내장했습니다. 원본 글꼴 파일은 동봉하지 않습니다.

아래 명령은 다른 출력 폴더에 생성하므로 기존 결과를 덮어쓰지 않습니다.

```sh
python3 build_pdf.py --output-root /tmp/water-in-one-ear-check
```

보존된 결과의 읽기 전용 검사:

```sh
python3 verify.py
```

최종 PDF를 PNG로 렌더하여 한 쪽 전체를 직접 읽었습니다. 원문 14행·4연, PDF 행별 글자·연 간격·글꼴 내장·경계·겹침을 확인했습니다. 배포 TXT는 원문과 바이트가 같습니다. 별도 사본에서 PDF·TXT가 바이트까지 동일하게 재생성되었습니다. 이는 같은 설치 환경에서의 결과입니다.

문학적 판단은 파일 검사와 별개입니다. 실제 낭독·인쇄·외부 독자 반응은 확인하지 않았습니다. `manifest.json`은 자신을 제외한 정식 보존 파일의 크기·SHA-256을 기록합니다. 임시 글꼴·페이지 렌더·캐시는 보존하지 않습니다.
