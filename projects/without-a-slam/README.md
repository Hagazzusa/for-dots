# 여섯 구짜리 걸쇠

‘화내지 않고 나가는 문소리’를 녹음하려는 두 폴리 아티스트의 짧은 희곡이다. 문을 닫는 사람과 소리의 표정을 고르는 사람이 달걀 포장을 사이에 두고 역할을 나눈다.

## 작품

- [읽기용 PDF · 4쪽](output/pdf/Without-a-Slam.pdf)
- [원문 TXT](play.txt)
- [배포용 TXT](output/text/Without-a-Slam.txt)

희곡 텍스트로는 완성 작품으로 선정했다. 실제 공연·낭독·녹음은 하지 않았으므로 공연 시간과 효과음의 성립은 미확인이다. 기존 작품의 인물이나 후속 설정이 아닌 독립적인 허구다.

## 검토와 수정

판정만 하던 지수가 직접 문을 잡고, 태오가 소리와 녹음을 맡는 변화가 대사 설명 대신 행동으로 드러난다. 마지막에는 소품이 소리를 내는 도구에서 노른자를 받는 그릇으로 돌아온다. 결말의 사고는 공연 타이밍에 따라 덧붙인 농담처럼 보일 가능성이 있어 실제 실연에서는 확인이 필요하다.

초고의 퇴장 횟수는 지문에 나오는 동작 수와 맞지 않아 특정 횟수를 삭제했다. 문 위로 손신호를 보내는 동작이 일반 방문 높이에 막히지 않도록 효과음용 문짝을 어깨 높이로 명시했다. 달걀 두 개와 여섯 구 포장의 관계, 의자 소품도 처음부터 밝혔다. 무대 장치의 안정성·식품 사용·관객에게 들리는 소리의 크기는 검증하지 않았다. 문 자체의 걸쇠음과 포장 소리가 겹치지 않도록 하는 실제 조절도 별도 실연 과제다.

## 제작과 재현

`python3 build_pdf.py`로 PDF와 TXT를 만든다. Python 3, ReportLab, fontTools, Noto Serif CJK가 필요하다. 기본 글꼴 위치는 코드에 표시되어 있으며 `FONT_LICENSE.txt`에 라이선스를 보존했다. 한 발화 또는 지문 단락을 쪽 사이에서 나누지 않고, 한국어 어절 단위로 줄을 바꾼다. 편집 원문은 UTF-8 TXT다.

다른 위치에 재생성하려면 `python3 build_pdf.py --output-root /tmp/without-a-slam-rebuild`를 실행한다. 같은 설치 환경에서 재생성한 PDF와 TXT의 바이트 일치를 확인했다. 다른 라이브러리·글꼴 버전까지 같은 결과를 보장하지 않는다.

`python3 verify.py`는 원문과 PDF 글자의 순서·일치(공백 제외), 배포 TXT의 바이트 일치, 모든 쪽의 글꼴 내장·여백·겹침과 매니페스트를 확인한다. 렌더한 최종 4쪽을 모두 육안으로 읽었다. 첫 조판의 어절 분리와 홀로 남는 마침표를 수정한 뒤 다시 렌더·검사했다. 실물 인쇄·배우 낭독·효과음 재생·관객 반응은 검증하지 않았다.

보존 파일은 원문·PDF·TXT, 조판 코드·글꼴 변환 코드·라이선스, README·검토 기록·검사 코드·매니페스트·캐시 제외 설정의 11개다. 미리보기 PNG와 임시 글꼴·캐시는 제외한다.
