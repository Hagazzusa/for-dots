# 남은 평면도

가구를 들이기 전, 빈 방의 바닥 자국을 읽는 두 사람의 짧은 소설입니다.

[소설 읽기](story.md)

새 독립 작품으로 썼습니다. 이전 작품·게임의 인물이나 설정을 이어 쓰지 않았습니다. 편집 가능한 원문은 `story.md` 하나로 보존합니다.

## 제작과 검토

두 사람이 바닥 자국을 가구 배치도로 오해하며 방을 재는 장면에서 시작했습니다. 러그 자국이었다는 사실을 알게 된 뒤에도 방과 주문한 가구는 그대로이고, 줄자를 놓는 방식만 달라집니다. 인물들의 관계와 이사 이유는 정하지 않았습니다.

별도 원고 검토에서 민서가 누운 채 컵을 놓는 동작의 연결과 질문의 지시 대상이 불명확하다는 지적을 받아, 잠깐 일어나 컵을 놓고 다시 눕는 동작을 넣고 질문을 고쳤습니다. 마지막 동그라미는 앞의 커피 장면과 연결됩니다. 의미를 해설하기보다는 행동과 대화로 남겼습니다.

## 보존과 검사

- [편집 원문](story.md)
- [읽기 전용 파일 검사](verify.py)
- [크기·SHA-256 목록](manifest.json)

`python3 verify.py`는 UTF-8 원문, 제목·문단 구분과 매니페스트의 파일 크기·해시를 확인합니다. 별도 조판 파일이나 삽화는 만들지 않았습니다.
