# 두 잔의 자리 — 독립 3D 뷰어

[Blender 정물](../second-cup/README.md)의 실제 메시를 키보드로 살펴보는 독립 Godot 프로젝트입니다. 게임이나 Blender 원본을 바꾸지 않습니다. 생성 콘셉트나 최종 렌더를 배경으로 띄우는 방식이 아닙니다.

## 열기와 조작

Godot **4.6.x Standard / Compatibility**에서 `project.godot`을 열고 F6가 아닌 **F5**로 실행합니다.

- **방향키**: 상판 위에서 제한된 범위로 회전합니다.
- **+ / −**: 확대·축소합니다. 키패드 + / −도 지원합니다.
- **L**: 주광원을 켜거나 끕니다. 약한 환경광과 보조광은 남습니다.
- **R**: 카메라와 주광원을 처음 상태로 돌립니다.

마우스 캡처·걷기·표적 이동·차 따르기 기능은 없습니다. 창이 포커스를 잃으면 카메라 입력을 처리하지 않습니다. 낮은 각도에는 제한이 있어 상판 아래로 내려가지 않습니다. 소품의 실제 메시 경계가 도움말·화면 밖으로 잘리지 않도록 관찰 각도와 창 크기에 따라 최소 거리를 늘립니다. 극단적으로 세로로 긴 창에서는 프레이밍을 우선하므로 Inspector의 확대·축소 상한보다 멀어질 수 있습니다. 상판 가장자리 전체 보존이 아니라 다섯 소품을 기준으로 합니다.

## 저장된 구성

- `scenes/tea_study.tscn`: 자체 포함 GLB 인스턴스. 모델은 움직이지 않습니다.
- `scenes/view_rig.tscn` / `scripts/view_rig.gd`: Inspector에서 지정한 타깃·각도·거리 범위와 카메라 입력을 소유합니다.
- `scenes/viewer.tscn` / `scripts/viewer.gd`: 환경·조명·읽기 전용 도움말을 조합하고 조명 상태를 소유합니다.

한국어 글꼴은 Noto Sans CJK이며 원본 라이선스를 `assets/fonts/`에 함께 보존했습니다. 이 안내는 저장소 전체에 새로운 라이선스를 부여하지 않습니다.

## 재질의 차이

Blender의 절차적 미세 표면·광학 경로를 그대로 이식한 것이 아닙니다. 금속·도기는 코어 PBR 근사치이고, 차는 원본 액체 형상을 유지한 **불투명 호박색 재질**입니다. 굴절·체적 흡수·유체·열 시뮬레이션이 없으며 Cycles 렌더와 동등한 외관을 보장하지 않습니다. 실제 식기의 제품·제작·식품 안전 검증도 아닙니다.

파생 파일의 출처와 재생성 방법은 `ASSET_README.md`를 참고합니다. 검증 기록은 `qa/headless_tests.json`, `qa/pack_tests.json`, `qa/native_qa.json`에 있습니다.


## 검증과 재현

Godot 4.6.3에서 소스와 실제 의존성으로 만든 PCK 각각 **1,342개 assertion, 실패 0**을 확인했습니다. 많은 항목은 9개 각도 조합에서 소품 144개 경계점을 화면에 투영하는 표본 검사입니다. 모든 창 크기·각도의 완전 증명이 아닙니다. 두 인스턴스 검사는 카메라 값·조명 상태의 독립성을 확인하며 하나의 viewport에서 여러 UI와 카메라를 동시에 운용하는 기능은 아닙니다.

```sh
godot --headless --editor --import
godot --headless --script res://tools/test_viewer.gd
# 출력 위치는 프로젝트 밖의 쓰기 가능한 디렉터리로 지정합니다.
godot --headless --script res://tools/build_pack.gd -- /tmp/second-cup-viewer.pck
```

패커는 저장된 장면·스크립트·GLB import remap와 생성 리소스·글꼴 및 라이선스의 실제 의존성만 포함합니다. exporter, 검사 도구, QA 그림은 런타임 PCK에 포함하지 않습니다. 테스트 스크립트는 QA JSON을 갱신하므로 읽기 전용 파일 검사와 구별하세요. 기본 오프라인 자산 해시는 `python3 verify_asset.py`로 검사합니다.

실제 네이티브 창에서 방향키 누름/떼기, 확대·축소 양끝, 위/아래 시점 한계, L 켜기/끄기, R 반복 복원과 640×480/1100×800 창을 확인했습니다. 첫 검사에서 밝게 날아간 도기와 상단 잘림을 발견해 조명·프레이밍을 고쳤습니다. [기본 화면](qa/native_preview.png)과 [작은 창](qa/native_small.png)은 실제 Godot 캡처입니다. 소프트웨어 렌더러에서 확인했으며 FPS 벤치마크나 다른 GPU의 동등한 외관을 주장하지 않습니다.

## 별도 차 재질 연구

[차 재질 한정 연구](../tea-material-study/README.md)는 alpha/PBR 후보를 기존 불투명 재질과 비교합니다. 높은 시점의 내부 명암은 일부 개선되었지만 컵 바닥 판독이 충분하지 않아 **통합을 보류**했습니다. 이 뷰어의 기본 차 재질과 자산은 그대로 유지합니다.
