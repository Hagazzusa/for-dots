# 두 잔의 자리 · 런타임 GLB 파생 에셋

`assets/second_cup_tableau.glb`는 [독립 Blender 정물](../second-cup/README.md)을 직접 돌려 보기 위한 **파생 에셋**입니다.
새 작품으로 원본을 대체하거나, Cycles 렌더를 실시간으로 똑같이 재현했다고 주장하지 않습니다.
원본 `.blend`·콘셉트·렌더와 기존 게임은 변경하지 않았습니다.

## 남긴 것과 뺀 것

- 차가 든 잔, 빈 잔, 빈 빵 접시 두 개, 주전자: **다섯 소품 모두 유지**했습니다.
- 컵의 내벽·굽·손잡이, 닫힌 차 체적과 0.8mm 메니스커스, 주둥이의 열린 보어와 벽, 손잡이 부속도 실제 형상입니다.
- 라운드 상판을 포함해 **19개 메시 / 62,072개 삼각형**입니다. 별도의 단순화·리토폴로지·Draco 양자화는 하지 않았습니다.
- 타일 벽, 아래 장식판, 원본 카메라·광원·패킹한 생성 콘셉트는 내보내지 않았습니다.
- 이미지·텍스처·베이크·외부 버퍼·애니메이션 없이 GLB 하나로 구성했습니다.

소보로는 아직 돌아오는 승객의 가방 안에 있고, 배우자가 준비한 집에는 잔과 접시가 기다립니다.
원래의 허구 서사를 유지하며, 실제 개인의 집이나 관계를 나타내지 않습니다.

## 좌표와 뷰어 연결

- **단위:** 미터. 뿌리 배율은 `(1, 1, 1)`입니다.
- **축:** Blender `(x, y, z)` → glTF/Godot `(x, z, -y)`.
- **원점:** 상판 윗면의 가운데. 상판 위는 `Y=0`, 아래는 약 `Y=-0.032`입니다.
- **전체 범위:** `(-0.65, -0.032, -0.52)` ~ `(0.65, 0.2279, 0.52)`.
- **소품만의 범위:** `(-0.274374, 0, -0.291320)` ~ `(0.290240, 0.2279, 0.330240)`.
- 원본 렌더에 대응하는 시점: 카메라 `(0.10, 1.13, 1.02)`, 주시점 `(-0.01, 0.038, -0.01)`, 세로 FOV 약 **25.36°**.

그룹은 `SC_NearCup`, `SC_FarCup`, `SC_NearPlate`, `SC_FarPlate`, `SC_Kettle`, `SC_Table`입니다.
그룹·메시 노드의 변환은 정리되어 있으며, 꼭짓점은 상판 기준 좌표입니다. 전체를 돌려 보는 데 맞춘 구조이지 각 부품에 재가공용 피벗을 배치한 CAD 구조는 아닙니다.

뷰어는 컵 내부가 보이는 높은 시점을 기본으로 두고, 너무 멀어져 잔과 접시가 작아지지 않도록 줌 범위를 잡는 편이 좋습니다.
얇은 림과 메니스커스를 검사하는 뷰어이므로 Godot import에서 자동 LOD 생성을 끄는 것을 권합니다.

## 재질: 같은 형상, 의도적으로 제한한 광학

| 이름 | Metallic | Roughness | 근사 |
| --- | ---: | ---: | --- |
| `SC_Ivory_Glaze` | 0 | 0.24 | 도기 기본색과 광택. 미세 요철·별도 코트층 없음 |
| `SC_Satin_Steel` | 1 | 0.38 | 금속 유지, 균일한 거칠기. 원본의 미세 변화·이방성 생략 |
| `SC_Charcoal_Handle` | 0 | 0.36 | 차콜 손잡이 |
| `SC_Dark_Base_Steel` | 0.8 | 0.40 | 어두운 금속 바닥과 핀 |
| `SC_Dusty_Plum_Porcelain` | 0 | 0.42 | 자두빛 상판. 절차적 미세 요철 생략 |
| `SC_Amber_Tea_Opaque_Approx` | 0 | 0.16 | **불투명 호박색 차 표면** |

정확한 선형 RGB 인자는 `export_audit.json`에 있습니다. 측정한 실제 재료 상수가 아니라 시각적 근사입니다.
재질은 core glTF metallic/roughness PBR만 사용하고, 모두 불투명·뒷면 컬링으로 내보냈습니다.

**차는 유리처럼 투명하지 않습니다.** 원본의 굴절·체적 흡수·액체 그림자 근사를 옮기지 않았고, 물속 컵 바닥도 보이지 않습니다.
실제 액체 메시와 수면·메니스커스는 남겼지만 실시간 표면 재질은 어두운 호박색의 불투명 근사입니다.
원본의 투과광 색을 정확히 복원했다는 주장을 하지 않습니다.
Godot의 알파 재질은 정렬·그림자·반사 등에 별도 제한이 있으므로, 단순히 알파 값을 낮춰 원본과 같은 액체라고 표시하지 않았습니다. [Godot 4.6 StandardMaterial3D](https://docs.godotengine.org/en/4.6/tutorials/3d/standard_material_3d.html)

**금속에는 반사 환경이 필요합니다.** diffuse ambient만 있는 장면에서는 검게 보일 수 있습니다.
뷰어에 sky radiance 또는 적절한 반사 환경과 절제한 주광원을 두어야 합니다. 과한 광량은 빈 잔의 바닥과 접시 안쪽을 희게 날릴 수 있습니다.
GLB에는 원본 광원이 없으므로, 이 파일만의 기하 검사로 최종 뷰어 화면 품질까지 보장하지 않습니다.

Godot는 glTF 2.0/GLB를 지원하고 권장하며, Blender 재질의 뒷면 컬링 설정도 import에 영향을 줍니다. [Godot 4.6 3D 형식 문서](https://docs.godotengine.org/en/4.6/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html)

## 재현과 수치 검사

Blender **4.3.2**에서 원본을 읽고, 모디파이어가 적용된 메시를 메모리 안에서 별도 복제했습니다.
원본 파일은 저장하지 않습니다. 광원·렌더 작업도 수행하지 않습니다.
검토한 원본 SHA-256과 다른 파일을 넘기면 조용히 진행하지 않고 중단합니다.

```sh
mkdir -p work
TMPDIR="$PWD/work" blender -b -t 2 --python-exit-code 1 \
  --python export_from_blender.py -- \
  --source ../second-cup/The_Second_Cup.blend

# GLB를 덮어쓰지 않고 원본과 다시 대조
TMPDIR="$PWD/work" blender -b -t 2 --python-exit-code 1 \
  --python export_from_blender.py -- \
  --source ../second-cup/The_Second_Cup.blend --verify-only

# Blender 없이 동결한 자산 파일과 GLB 기본 구조 검사
python3 verify_asset.py
```

공개 저장소에서는 위 형제 경로를 사용합니다. 다른 위치의 원본에는 `--source`로 실제 파일을 지정합니다.

`export_audit.json`은 실제 GLB의 버퍼·인덱스·노드 변환을 읽어 다음을 확인합니다.

1. 원본 `.blend`의 실행 전후 SHA-256이 같음.
2. 19개 구성 메시, 소품 다섯 그룹과 상판 유지.
3. 원본 평가 메시와 GLB의 모든 위치 및 **방향을 포함한 삼각형 집합**이 0.1µm 좌표 반올림 기준에서 동일함.
4. 삼각형 수·부호 있는 체적·유한한 단위 법선 유지.
5. 외부 이미지·텍스처·버퍼·카메라·광원·애니메이션 없음.
6. 정해진 PBR 재질 여섯 개, 투과/체적 등의 광학 확장 없음.

법선 경계 때문에 GLB 꼭짓점 수는 원본보다 늘 수 있습니다. 이를 형상 변경으로 오인하지 않도록 실제 삼각형 위치를 비교합니다.
이 비교는 **GLB 바이너리까지**의 검증입니다. Godot importer의 이후 압축·LOD, 뷰어 조명·색 관리·화면 품질은 별도 런타임 검증 대상입니다.
뷰어의 실제 import·native 검사는 [뷰어 README](README.md)의 범위와 기록을 따릅니다.

파일 목록과 해시는 `asset_manifest.json`, 출처는 `asset_provenance.json`에 있습니다.
이 하위 manifest는 뷰어 전체가 아니라 이 파생 자산과 export 도구만 다룹니다.
제품 제조·식품 접촉·내열성·손잡이 강도·유체 거동을 인증하는 모델이 아닙니다.
