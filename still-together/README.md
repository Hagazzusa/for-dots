# 아직 출발하지 않은 밤

비에 젖은 차의 앞유리 바깥에서, 같은 공간에 앉아 있는 두 실루엣을 바라보는 독립적인 벡터 정물이다. 얼굴, 이름, 대사, 관계를 설명하는 문구는 그림에 넣지 않았다. 대시보드 중앙의 작은 황토색 표시등만 히터의 약한 온기를 암시한다.

## 기존 작품과 다른 시점

`beside-you/README.md`를 확인했다. 기존 「옆자리 / Beside You」는 히터 스위치, 팬, 옷감과 빗소리로 차 **안에서 듣는** 38초 오디오 작품이며 인물 그림은 없다. 이번에는 차 **밖에서 앞유리를 보는** 정지 구도로 바꾸었다. 기존 오디오를 복제하거나 재생하지 않았고, 새 사운드를 만들지 않았다.

현재 갤러리의 「강이 지나가는 동안」은 창의 안쪽에서 바깥 강변을 보는 수평 풍경이다. 이번 그림은 두 사람이 유리 너머에 있고 관찰자는 바깥에 있는 반대 시점이다. 좌석과 어깨를 분리하고, 창틀·사이드미러·쉬고 있는 와이퍼와 운전대를 넣어 창과 두 사람을 읽을 수 있게 했다.

기존 `after-the-rain/config/story_car.tres`의 정차한 차, 앞자리의 두 사람과 히터의 낮은 소리를 확인했다. 그림은 그 배경에서 출발한 동반 상상이며, 실제 사람의 사진이나 새 게임 장면이 아니다. 특정한 인물의 얼굴, 나이, 성별 표현을 확정하지 않는다.

## 제작과 확인

원본은 `still_together.svg`다. 이름이 있는 그룹으로 두 인물, 창, 비, 히터 표시등, 차체를 나누었다. 모두 직접 작성한 SVG 도형이며 글꼴·사진·이미지 생성·외부 소재가 없다. 빗물은 선과 작은 타원으로 표현했고, 실제 굴절이나 물리적 젖음 시뮬레이션을 주장하지 않는다.

Inkscape 1.4에서 1200 × 825 PNG를 실제 렌더하여 두 실루엣과 창틀, 낮은 표시등이 읽히는지 확인했다. 초안 렌더는 `inkscape still_together.svg --export-type=png --export-filename=still_together_proof.png --export-width=1200`으로 재현한다. 수정 검토에서 외부 정면 관찰자 기준 좌우를 대조해 운전대를 보는 사람의 오른쪽으로 옮겼다. 다른 도형은 그대로 유지했다. 이후 최종 3200 × 2200 PNG를 직접 렌더하고 확인했다. 영상·뷰어·게임 구현은 포함하지 않는다.

제작일: 2026-11-03.

## 최종 재현과 파일

설치된 Inkscape에서 `bash render.sh`를 실행하면 같은 폴더의 `still_together.png`를 덮어쓴다. 재현에는 외부 다운로드나 글꼴이 필요 없다.

- `still_together.svg`: 편집 가능한 원본 도형.
- `still_together.png`: 3200 × 2200 최종 그림.
- `render.sh`: 직접 렌더하는 스크립트.
- `README.md`: 출발점, 새 상상의 범위와 제작 설명.
- `verification.json`: 크기, 외부 참조와 메타데이터 검사.
- `SHA256SUMS`: 파일 검증용 해시.
