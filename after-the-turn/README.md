# 회전이 멎은 뒤

문이 열린 세탁기와 바닥의 빈 빨래 바구니를 사선으로 바라보는 독립 벡터 작품이다. 누가 다녀갔는지, 언제 돌아올지, 기존 인물과 어떤 관계인지 정하지 않았다. 기존 게임의 새 장소나 실제 제품 사진이 아니다. 오른쪽 창 밖에서 들어오는 빛이 바닥과 바구니 옆을 비춘다. 실내 기계에서 빛이 나오는 장면이 아니다.

## 공간 설계

1600 × 1200 원본 좌표에서 세탁기 앞면은 x445–845, y236–893이다. 오른쪽 옆면을 보여 주어 방 안에서의 깊이를 만들고, 큰 드럼 원형과 왼쪽으로 열린 문을 분리했다. 카메라의 정확한 3D 투영이 아닌 양식화한 사선 구도다.

바구니는 기계 오른쪽 앞 바닥에 둔다. 상단은 x1023–1350, y761–825이고 밑면은 y936–978에 닿는다. 높이는 기계의 약 3분의 1, 폭은 앞면의 약 5분의 4로, 1회 세탁물을 담는 작은 가정용 바구니를 상상했다. 기계 입구를 가리지 않으며, 열린 문이 차지한 왼쪽 공간과도 겹치지 않는다. 바닥 접촉 그림자와 어두운 안쪽 면으로 빈 바구니의 위치와 깊이를 나타낸다. 수치는 화면상의 설계 기준이며 실제 제품 치수·접근성·안전성 검증은 아니다.

## 파일과 제작 환경

- `after_the_turn.svg`: 직접 그린 편집 가능한 도형. 기계, 문, 바구니, 창과 빛을 그룹으로 구분한다.
- `after_the_turn.png`: Inkscape 1.4에서 직접 렌더한 3200 × 2400 최종 PNG.
- `render.sh`: 최종 PNG 재현 스크립트.
- `verification.json`: 파일·외부 자원·메타데이터·렌더 재현 검사.
- `SHA256SUMS`: 작품 파일의 무결성 해시.

재현: 설치된 Inkscape 1.4 환경에서 `bash render.sh`를 실행한다. 같은 폴더의 `after_the_turn.png`를 덮어쓰므로 수정본을 보존하려면 먼저 복사한다. Python, 외부 글꼴, 인터넷 연결은 렌더에 필요 없다.

외부 이미지·사진·폰트·생성형 이미지·외부 텍스처를 사용하지 않았다. 빛, 유리, 금속은 단색과 겹친 도형으로 표현하며 물리 시뮬레이션을 주장하지 않는다. 작은 미리보기를 실제로 열어 기계와 열린 문, 바구니의 위치를 확인하고 바구니 안쪽을 어둡게 정리했다. 영상이나 뷰어는 만들지 않았다.
