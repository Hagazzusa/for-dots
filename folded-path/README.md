# 접힌 길 · Folded Path

책상 크기의 독창적인 움직이는 종이 연구입니다. 따뜻한 상아색 아코디언 패널 위로 차분한 청록색 선 하나가 이어집니다. 가파른 접힘이 천천히 풀려 작은 풍경이 되고, 잠시 머문 뒤 다시 닫힙니다. 크고 따뜻한 면광원과 오트밀색 바닥이 선과 그림자에 시선을 모읍니다.

## 제작 가능성을 주장하지 않는 모델

두께가 0인 0.8 × 1.8 단위 강체 표면 조각 여섯 개를, 전체 힌지 모서리가 일치하도록 운동학적으로 연결했습니다. 이들은 별도 메시 오브젝트이며 **위상적으로 용접된 한 장의 종이가 아닙니다**. 진정한 종이접기, 실제 종이의 탄성, 유한 두께에서의 간격, 접힘 내구성, 제작 준비 완료를 주장하지 않습니다. 잉크는 공중에 뜬 곡선이나 데칼이 아니라 각 패널 표면 안에 재질을 지정한 좁은 면 띠입니다. 이웃한 띠의 끝점은 힌지에서 일치합니다.

각 패널은 앞 패널의 정확한 먼쪽 모서리에 부모 연결되어 있습니다. 번갈아 나타나는 경사는 ±66°에서 ±22°까지 변합니다. 모든 방향이 ±90° 안에 있어 패널은 X축을 따라 단조롭게 정렬된 영역을 차지합니다. 따라서 이 이상화된 압출 형상에서 인접하지 않은 패널끼리는 교차할 수 없습니다. 정수 키 사이의 회전은 강체로 보간되므로 렌더 프레임 사이에서도 패널 길이와 모서리 폐합을 유지합니다.

## 재현

Blender 4.3+가 필요하며 FFmpeg는 선택 사항입니다. 다운로드한 에셋이나 Python 패키지는 필요하지 않습니다.

```sh
blender -b -t 2 --python build.py
blender -b -t 2 --python build.py -- --still
blender -b -t 2 --python build.py -- --loop
blender -b -t 2 --python verify_saved.py
python3 sanitize_png.py
ffmpeg -y -framerate 12 -i frames/frame_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 20 -movflags +faststart -map_metadata -1 folded_path.mp4
```

이 디렉터리에서 실행하거나 `build.py` 경로를 전달하세요. 결과는 항상 스크립트 옆에 저장됩니다. 압축된 `.blend`에는 편집 가능한 모든 메시, 재질, 조명, 힌지 변환 키프레임이 남아 있습니다. 완화된 자세인 24프레임에서 열립니다. 49번째 키가 주기 경계를 닫으며, 렌더 프레임은 12 fps의 1–48프레임(4초)입니다. 렌더링은 CPU 전용, 스레드 두 개로 고정하며 Blender 작업을 한 번에 하나씩 실행합니다. OpenImageDenoise가 없는 빌드를 위해 디노이징을 의도적으로 껐습니다.

## 검증과 한계

`verification.json`은 빌드할 때마다 다시 생성합니다. 렌더링한 48개 자세 모두에서 좌표의 유한성, 패널 길이, 인접하지 않은 X축 영역의 순서, Blender로 평가한 전체 힌지 모서리 폐합을 검사합니다. 이는 이상화된 기하 검사이며 물리 시뮬레이터나 포괄적인 일반 충돌 검사가 아닙니다. 정지 이미지와 반복 영상은 예술적 미리보기입니다. 공개 산출물에 외부 에셋, 사용자 식별자, 절대 파일시스템 경로, 텍스트 도장, 소스 메타데이터를 의도적으로 포함하지 않았습니다.

팔레트는 따뜻한 상아색 종이, 채도를 낮춘 청록색 안료, 오트밀색 책상입니다. 지오메트리, 조명, 구도, 움직임은 이 연구를 위해 제작했습니다.

## 제공한 미리보기 품질 검사

800 × 640 정지 이미지는 64샘플을 사용합니다. 480 × 384, 48프레임, 12 fps 반복 영상은 16샘플을 사용하며 어두운 접힘에 몬테카를로 입자가 보입니다. 1, 12, 24, 36, 48프레임을 육안으로 확인했고, 첫 렌더 프레임과 마지막 렌더 프레임의 픽셀 배열이 동일합니다. 독립적인 저장 장면 검증기는 1/4프레임과 닫힘 경계를 포함해 193개 자세를 검사합니다. 전체 힌지와 잉크 끝점의 최대 틈은 0이고, 폭 오차는 2.71e-7 단위 미만이며, 인접하지 않은 X축 간격은 0.325389 단위를 넘습니다. 두 검증 JSON 파일과 `render_verification.json`을 참고하세요.

PNG 메타데이터는 압축된 픽셀 페이로드를 바꾸지 않고 제거했습니다. MP4에는 일반적인 코덱/컨테이너 메타데이터만 있습니다. 저장한 장면의 렌더 출력 경로는 상대 경로입니다.

## 이식 가능한 공개 사본

공개 사본은 저장된 파일 탐색기 디렉터리를 `//`로 정규화했으며, 렌더 출력은 이미 상대 경로입니다. 지오메트리, 재질, 애니메이션은 변경하지 않았습니다. `artifact_manifest.json`이 포함된 사본을 식별합니다. 장면은 직접 작성한 드라이버나 내장 텍스트 스크립트 없이 키프레임 변환을 사용합니다. 일반적인 Blender 내장 런타임 핸들러는 이 설명의 대상이 아닙니다.
