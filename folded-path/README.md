# 접힌 길 · Folded Path

An original desk-scale kinetic-paper study: warm ivory accordion panels carry one muted-teal line. The steep folds slowly relax into a small landscape, rest, then close again. A large warm area light and an oatmeal ground keep attention on the line and its shadows.

## Model, not a manufacturing claim

Six 0.8 × 1.8 unit, zero-thickness rigid surface patches are connected kinematically by coincident full hinge edges. They are separate mesh objects, **not a topologically welded sheet**. No claim of true origami, physical paper elasticity, finite-thickness clearance, crease durability, or fabrication readiness is made. The ink is a narrow strip of material-assigned faces within each panel surface, not a hovering curve or decal. Neighboring strip endpoints agree at hinges.

Each panel is parented to its predecessor's exact far edge. Alternating slopes range from ±66° to ±22°. Every orientation remains within ±90°, so panels occupy monotonically ordered X slabs: nonadjacent panels cannot intersect in this idealized extrusion. Rotations interpolate rigidly between integer keys; this maintains panel lengths and edge closure between rendered frames as well.

## Reproduce

Requires Blender 4.3+ and optionally FFmpeg; no downloaded assets or Python packages.

```sh
blender -b -t 2 --python build.py
blender -b -t 2 --python build.py -- --still
blender -b -t 2 --python build.py -- --loop
blender -b -t 2 --python verify_saved.py
python3 sanitize_png.py
ffmpeg -y -framerate 12 -i frames/frame_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 20 -movflags +faststart -map_metadata -1 folded_path.mp4
```

Run from this directory, or pass the path to `build.py`; outputs are always next to the script. The compressed `.blend` retains all editable meshes, materials, lights and keyed hinge transforms. It opens at the relaxed pose, frame 24. A 49th key closes the periodic seam; rendered frames are 1–48 at 12 fps (4 seconds). Rendering is CPU-only, fixed at two threads, one Blender job at a time. Denoising is deliberately disabled for builds without OpenImageDenoise.

## Verification and limitations

`verification.json` is regenerated by every build. All 48 rendered poses are checked for finite coordinates, panel lengths, ordered nonadjacent X slabs and Blender-evaluated full-edge hinge closure. Those are idealized geometric checks, not a physical simulator or exhaustive general collision test. The static image and loop are artistic previews. No external assets, user identifiers, absolute filesystem paths, text stamps or source metadata are intentionally included in the public artifacts.

Palette: warm ivory paper, desaturated teal pigment, oatmeal desk. Geometry, lighting, composition and motion were authored for this study.

## Delivered preview QA

The 800 × 640 still uses 64 samples. The 480 × 384, 48-frame, 12 fps loop uses 16 samples and retains visible Monte Carlo grain in darker folds. Frames 1, 12, 24, 36 and 48 were visually inspected; first and last rendered pixel arrays are identical. The independent saved-scene verifier checks 193 poses, including quarter frames and the closing seam: maximum full-hinge and ink endpoint gaps are zero, width error is below 2.71e-7 units, and nonadjacent X clearance exceeds 0.325389 units. See both verification JSON files and `render_verification.json`. PNG metadata is removed without changing compressed pixel payloads; the MP4 carries only ordinary codec/container metadata. The saved scene render destination is relative.

## Portable publication copy

The publication copy normalizes the saved file-browser directory to `//`; render output is already relative. No geometry, material or animation changes were made. `artifact_manifest.json` identifies the included copies. The scene uses keyed transforms with no authored drivers or embedded text scripts; ordinary built-in Blender runtime handlers are not part of that claim.
