# 바람이 앉는 자리 · 움직임 연구

공개한 정지 원본은 바꾸지 않고 별도 폴더에서 시작한 움직임 연구다. 먼저 세 장의 키프레임을 검토한 뒤, 같은 변형으로 짧은 무음 영상을 만들었다. 

## 움직임 제안

- 12초 호흡을 가정한 0초, 4초, 8초 장면이다.
- 커튼의 원래 Bézier 경로와 접힌 색면을 바탕으로 한다. 높이 가중 함수는 봉 높이에서 값과 기울기가 0이며, 실제 곡선은 제어점 변형 근사로 꼭대기 끝점을 고정한다. 첫 제어점은 움직일 수 있으므로 꼭대기의 곡선 접선 방향까지 고정되지는 않는다.
- 높이가 내려갈수록 smoothstep 가중치로 좌우 이동량이 커진다. 왼쪽 밑단의 최대 이동은 11px, 오른쪽은 7px다. 1600px 폭 기준으로 0.7% 미만이다.
- 두 커튼에는 0.65라디안의 위상차를 두었다. 강체 회전이나 통째 평행 이동이 아니며, 커튼의 그림자도 같은 방향으로 조용히 따른다.
- 의자, 창틀, 바닥, 햇빛은 전혀 움직이지 않는다. 소리는 없다.
- 향후 웹 재생을 만들 경우 `prefers-reduced-motion: reduce`에서는 공개한 정지 SVG만 보여 주고 재생하지 않는다. 이번 단계에서는 웹 자동 재생 코드를 만들지 않았다.

## 재현

설치된 Python과 Inkscape로 `python build_keyframes.py`를 실행한다. 원본은 이웃 폴더 `a-seat-for-wind`의 SVG를 읽기만 한다. 결과는 각각 편집 가능한 SVG와 1600 × 1200 PNG다. 사진, 생성형 이미지, 래스터 편집은 사용하지 않았다.

보간은 Bézier 제어점과 끝점을 같은 높이 함수로 변형한다. 수평·수직 선 명령은 일반 선 명령으로 정규화하고, 각 프레임에서 같은 경로 구조와 점 수를 사용하므로, 후속 단계에서도 급격한 경로 전환 없이 연속적인 경로 보간을 사용할 수 있다.

## 12초 영상

후속 제작 파일 `a_seat_for_wind_motion.mp4`는 같은 변형 함수로 만든 180장의 SVG를 Inkscape 1.4에서 직접 렌더하고, ffmpeg의 H.264 코덱으로 묶은 960 × 720, 15fps 무음 영상이다. `python build_loop.py`로 재현한다. 중간 SVG/PNG는 임시 폴더에서 만들고 작업이 끝나면 정리한다. 래스터 후처리나 광학 흐름 보간은 없다.

위치 함수는 `A sin(2πt/12 + φ)`이고 속도는 그 도함수다. 0초와 12초에서 두 값 모두 일치하며, 끝점을 중복 저장하지 않아 마지막 프레임에서 첫 프레임으로 정상적인 한 프레임 간격으로 이어진다. 매 프레임에서 커튼 이외 그룹이 원본과 동일한지 검사한다. `verification.json`에는 프레임 수, 길이, 코덱과 전체 디코드 결과를 남긴다.

MP4 자체는 운영체제의 모션 줄이기 설정을 감지할 수 없다. 모션 줄이기가 필요한 경우 원본 정지 PNG/SVG를 사용한다. 향후 웹 재생기를 추가하면 `prefers-reduced-motion`에서 정지 원본을 보여 주도록 한다.

## 재생 확인의 범위

임시 ffplay 창에서 실제 MP4를 재생하고 일시 정지, 끝부분 탐색, 재개 및 반복 재생 상태를 확인했다. 원격 화면 도구는 연속 영상 대신 간격이 있는 화면을 제공하므로, 루프 경계의 모든 순간을 눈으로 관찰했다고 주장하지 않는다. 경계의 연속성은 주기 함수의 위치·속도 검사와 180프레임 전체 생성·디코드 검사를 함께 근거로 삼는다. 원본 정지 작품은 변경하지 않는다.

재현에는 Python 3, Inkscape, H.264 인코더가 포함된 FFmpeg/ffprobe가 필요하다. 스크립트는 이 폴더의 키프레임·영상·검증 JSON을 다시 쓰므로 보존할 결과가 있으면 별도 사본에서 실행한다. 공개 사본의 원본 참조는 이웃 `a-seat-for-wind/`이며 영상과 키프레임 바이트는 최초 결과와 같다.
