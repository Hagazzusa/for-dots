# 꽃이 떠난 자리

포장지 한 귀퉁이가 접혀 있고, 잘라낸 잎줄기 하나와 풀린 끈이 남아 있다. 꽃다발이 있었을 자리는 비워 두었다.

비 오는 동네의 꽃집에서 이어 상상한 독립 벡터 정물이다. 누가 꽃을 포장했는지, 어떤 손님에게 갔는지, 기존 인물과 어떻게 연결되는지는 정하지 않는다. 실제 작업대 사진이나 게임 화면이 아니다.

## 공간과 매체

하나의 직교투영 카메라로 작업대를 비스듬히 내려다본다. 모든 도형은 같은 3차원 좌표와 투영식을 거쳐 SVG의 평면 다각형이 된다. 서로 다른 부분에 임의의 소실점을 부여하지 않는다. 직교투영이므로 같은 방향 평행선은 화면에서도 평행하다.

포장지는 약 0.53 × 0.52, 실패는 지름 0.152·높이 0.121의 구성용 단위로 잡았다. 두 물체의 x방향 간격은 0.069이다. 실패 밑면은 작업대 z=0에 있고, 종이는 얇은 층으로 포개진다. 잎줄기는 위쪽 종이 표면에 놓인다. 풀린 끈은 종이를 가로지르지 않도록 작업대 위로 둘렀다. 이는 장면 배치를 위한 값이지 실제 제품·종이·식물의 측정이나 제작 치수가 아니다.

넓은 종이 면과 가는 끈의 선을 중심으로 삼아 이전 빨래방의 정면 공간과 구도를 구분했다. 꽃집이라는 맥락은 작업 뒤 남은 작은 잎줄기로만 암시한다.

## 자체 검토와 수정

실제 초안에서 카메라 상하 축과 종이의 겹침 순서를 바로잡았다. 실패에 추가했던 가는 띠는 가림 검사에서 12개 표본의 잘못된 앞뒤 순서를 만들어 제거했다. 불필요한 장식을 줄인 수정본을 다시 렌더하고 확인했다.

카메라 기저의 직교·단위 길이, 위쪽 방향, 작업대 아래로 내려가는 형상의 부재, 실패의 접지, 종이와 실패의 분리, 끈과 종이 영역의 비겹침을 검사한다. SVG 면의 그리기 순서와 광선-평면 교차 깊이를 별도로 비교했다. 1600 × 1200 기준 좌표에서 10px 간격의 유한 격자이며, 면 위 3133개 표본 중 겹침 2608개에서 순서 오류가 없었다. 모든 픽셀·곡선·선 굵기·가능한 시점의 증명은 아니며 두 계산은 같은 카메라 정의를 공유한다.

## 파일과 재현

- `after_the_flowers.svg`: 편집 가능한 원본 벡터. 각 면의 `data-part` 속성으로 부위를 식별한다.
- `after_the_flowers.png`: 직접 렌더한 3200 × 2400 PNG.
- `build.py`: 구성 좌표와 카메라로 SVG를 만들고 PNG를 렌더한다.
- `check.py`: 다시 빌드한 뒤 유한 표본의 가림 순서를 검사한다.
- `geometry_check.json`, `occlusion_check.json`: 실제 검사 결과.
- `public_review.json`: 외부 참조·메타데이터·반복 렌더 검사 기록.
- `SHA256SUMS`: 공개 후보 파일의 해시.

설치된 Python 3 표준 라이브러리와 Inkscape 1.4를 사용한다. `PYTHONDONTWRITEBYTECODE=1 python check.py`로 다시 만들고 검사할 수 있다. 같은 폴더의 SVG·PNG·검사 JSON을 덮어쓴다. 글꼴·외부 이미지·사진·외부 텍스처·생성형 이미지·네트워크 다운로드는 사용하지 않는다.

## 표현의 한계

접힌 모서리는 강체 삼각형 근사이며 종이의 물리적 접힘을 시뮬레이션하지 않는다. 실패의 가운데 구멍은 어두운 표면 표시다. 접촉부의 색면은 그림을 위한 표현이며 조명·그림자 계산이 아니다. 잎은 이름을 정하지 않은 양식화한 도형으로 식물 종을 재현하지 않는다. 끈은 평면 곡선이며 실제 장력·감김·매듭은 검증하지 않았다. 기존 작품이나 게임 구현을 대체하지 않는다.
